# 0. Executive Summary

9月2日の視察で確認できたことを7点に整理する。

**1｜「大野の水」は単一ではない。用途によって、まったく違う水が使われている。**
これが2日目の最大の発見である。**醸造（酒・醤油）は地下40〜50mの深層地下水**を汲み上げる。**一般家庭は地下10〜20m**。**稲作は地下水ではなく、九頭竜川から引いた表流水**を使う。同じ「名水の町」の内側に、少なくとも3層の異なる水利用が併存している。9月1日に整理した「水が共通基盤」という理解は、**「同一の水」ではなく「同一の水系」の共有**として精緻化する必要がある。

**2｜9月1日に保留した「地域固有性」の問いに、醤油と酒の側から答えが出た。**
9月1日、酢の生産者は「酢に地域性は薄い」と明言した。しかし醤油では、**福井県内18社のうち麹づくりから一貫して醤油を作るのは1社のみ**であり、その1社が大野にある。さらに「**盆地特有で冬は雪が降り夏は暑い。だから温度管理をしなくても良い醤油ができる**」と、気候と製法が直接結びつけて語られた。酒でも、地元産五百万石が全国屈指の生産量であること、地下50mの伏流水を「山の恵み」と呼ぶことが確認された。**地域固有性は、酢ではなく醤油と酒の側に存在する。**

**3｜受入キャパシティが、どの現場でも共通の制約になっている。**
酒蔵は「**ミーティングルームは最大20人、宿泊を伴う本格研修は3人×2班で6人がマックス**」と明言した。牧場の体験は10人以上で開催、醤油の体験は**人手不足と夏季の熱中症対策のため現在停止**している。9月1日の酢蔵は4.5人体制だった。**高付加価値・少人数型が「望ましい」のではなく、それ以外が物理的に成立しない。**

**4｜酪農は、地域産業として崩壊の途上にある。**
福井県の酪農家は**100軒以上から15軒**に減少。**県内に牛乳工場がなく**、生乳を石川県まで運び製品にして運び戻している。訪問した牧場は、放牧・ジャージー種・6次産業化という3点で県内ほぼ唯一の存在だが、**委託加工先の大工場化により原料乳の加工を断られ、牛乳が売れなくなっている。**

**5｜六呂師高原には、資源と「頓挫の履歴」の両方がある。**
標高約600m、**星空の国際認定（アーバン・ナイト・スカイプレイス）**、北陸最大級の天体望遠鏡、県のキャンプ施設、音楽フェスのソールドアウト実績。一方で、**リゾート法時代の開発計画、県の乳製品体験施設、ゴルフ場計画がいずれも頓挫**し、旧民間施設は太陽光パネルに転用され、スキー場は倒産している。

**6｜「水の里」を掲げながら、水が見えない。**
視察者側から率直な指摘があった。「**水の里と言っている割に、街中に水が溢れていない**」「**側溝に全部蓋をしてしまっている**」。一方、酒蔵で発見された江戸期の井戸には強い反応があり、「**ああいうのをコースに入れなければダメだ**」と述べられた。資源そのものではなく、**可視性の設計**が課題である。

**7｜行政側自身が、ブランディングと価格設定の不在を課題として認識している。**
「基本となる水と、混じり気なしで作られた農産物がみんな美味しい。ただ、**私たちはそこのところがちゃんとブランディングできていない。農家さんも控えめで、安くないと売れないんじゃないかと思ったりして、価格設定がうまくいかない**」という発言があった。9月1日に整理した産業課題と、行政側の自己認識が一致している。

# 2. 地域概観 — 移動中に確認された事項

## 2-1. 商業と観光の変化

**FACT**

- 大野市に**セブン-イレブンが初出店した。**ローソン・ファミリーマートは以前から複数あったが、セブン-イレブンのみ出店がなかった。
- 今年、**はま寿司**とカレーチェーンが出店した。すき家はかなり以前からある。吉野家・松屋はない。
- 出店の背景として、**観光客の増加**が挙げられた。

**OBSERVATION** — チェーン店の出店は、それ自体が観光価値になるものではない。しかし**外部資本が「商圏として成立する」と判断した**という事実であり、来訪者数の変化を示す独立した傍証になる。

## 2-2. 地形と水系

**FACT**

- 大野は盆地であり、**周囲のすべての川が九頭竜川に合流**して勝山方面へ流れる。市街地のお堀の西側を通る赤根川、清滝川、真名川などが確認された。
- 九頭竜川は福井県で最も大きい一級河川。真名川も一級河川。九頭竜川・真名川の上流にはダムがあり、治水が図られている。
- 周囲は**1500m級の山**に囲まれる。**荒島岳＝日本百名山、経ヶ岳＝日本三百名山、能郷白山＝日本二百名山**。「百名山・二百名山・三百名山が一つの市にあるのは珍しい」と説明された。
- 九頭竜川は急流であり、**落差を利用した発電**が多い。北陸電力が発電に用いた後、水は必ず水路に流される（第7章参照）。

## 2-3. 交通とメディア

**FACT**

- **中部縦貫自動車道**は勝山であと約15kmが未開通。**東海北陸自動車道とつながると名古屋方面・高山方面がかなり近くなる。**
- **スキージャム勝山**は関西圏からのアクセスが良く人気。**人工降雪設備がある**（大野市内のスキー場にはない）。和泉地区は標高が高く県境で積雪が非常に多い。
- 福井県の民放テレビは**2局のみ**（福井放送＝日テレ系、福井テレビ＝フジ系）。ケーブルテレビに加入しないと視聴できない系列がある。嶺北と嶺南で視聴環境が異なる。

**OBSERVATION** — 民放2局という事実は、**県内向けのマス媒体による情報流通が構造的に細い**ことを意味する。9月1日に確認された「情報発信不足」という課題は、努力の問題だけでなく媒体環境の問題でもある。

# 3. 六呂師高原

## 3-1. 確認事項

**FACT**

- 大野市六呂師。**標高約600m**。市街地から車で約20分。
- **星空に関する国際認定（アーバン・ナイト・スカイプレイス）を受けている。**
- **北陸最大級の天体望遠鏡**があり、**プラネタリウム**も設置されている。予約制で利用可能。
- 県の宿泊施設（青少年の自然の家）があり、**300〜400人が宿泊可能。**
- **ハンモックで星空を鑑賞する**プログラムが、ミルク工房の指定管理者によって実施されている。
- **県のキャンプ施設「妻と大地」が昨年7月にオープン**した。
- **ミルク工房**：アイスクリーム作り・バター作りの体験、レストラン、ソフトクリーム販売。
- **温浴施設**がある。
- 昨年8月、**音楽フェスが開催され、テントサイト付きのチケットが完売した。**
- スキー場だった斜面が正面にあり、サッカーができる広場がある。

## 3-2. 頓挫の履歴

**FACT** — 六呂師では、過去に複数の開発計画が実現しなかった。

| 計画 | 経緯 |
| :-- | :-- |
| リゾート開発（リゾート法時代／昭和末〜平成初め） | スイス的な牧歌的風景を活かし、体験・飲食・入浴・宿泊を構想したが実現せず |
| ゴルフ場 | 頓挫 |
| 県の乳製品体験施設 | 乳搾りからアイスクリーム製造までを体験できる計画。**殺菌機の費用が高く**実現せず |
| 民間の温泉・キャンプ・コテージ施設 | 現在は**太陽光パネル**に転用された |
| スキー場 | **倒産**。現在は別会社が運営。同社は羊の飼育を始めている |

**FACT** — 六呂師（南六呂師）には酪農団地があり、かつて5〜6軒の酪農家がいた。現在は数軒に減っている。

## 3-3. 観察

**OBSERVATION** — 六呂師には、**資源と、資源を活かそうとして失敗した履歴の両方が蓄積している。**確認された頓挫要因は、（a）設備投資額（殺菌機）、（b）バブル崩壊という外部環境、（c）事業体の経営破綻（スキー場）であり、いずれも**資源の質ではなく事業設計・資金構造に起因する。**

**OBSERVATION** — 一方、近年の取り組み（キャンプ施設、音楽フェスのソールドアウト、星空プログラム）は**小規模・低投資で成立している。**過去の大型計画との対比が明確である。

**INSIGHT** — 六呂師について検討する場合、**過去の頓挫は「ここでは無理だ」という証拠ではなく、「大型ハード投資が成立しなかった」という条件情報**として扱うべきである。近年の小規模な取り組みが成立していることは、規模の設計が成否を分けた可能性を示す。ただし各計画の詳細な経緯は当日の記録からは確認できていない。

**NEXT QUESTION**

- キャンプ施設「妻と大地」の稼働率、客層、単価。
- 音楽フェスの来場者数、県外比率、宿泊誘発。
- 星空認定の要件と、それが課す照明等の制約。

# 4. 酪農

## 4-1. 訪問先の概要

**FACT** — ラブリー牧場（勝山市平泉寺町小矢谷）。

- 経営者は**金沢の街中の生まれ**で、農家出身ではない。「動物と一緒に暮らす仕事はないか」と考え、北海道・熊本・石川で研修した後、**31歳で独立。40年が経過**している。
- **放牧にこだわり、放牧できる場所を探し回って福井県に来た**と説明された。
- 日本の酪農の主流は**「つなぎ飼い」**（コンクリートの上で繋ぎっぱなし）。**「北陸ではうちだけ」**というほど放牧は少なく、北海道でもほとんどないと述べられた。

## 4-2. 飼養の実態

**FACT**

| 項目 | 内容 |
| :-- | :-- |
| 品種 | **ジャージー種**。日本の乳牛130万頭のうちジャージーは約1万頭＝**約130分の1** |
| 頭数 | 成牛16頭、育成を含め約30頭、子牛5頭 |
| 雇用 | **16頭の乳で約20名を雇用**（売店2店舗、菓子製造所を含む） |
| 頭数の推移 | 開始時20頭、最大22〜23頭まで増やしたが**現在は減らしている**。「販売する分だけ絞れればいい」 |
| 牧草地 | 奥行き約1km、**8ヘクタール。8ブロックに分けて輪換放牧** |
| 搾乳 | 昔ながらのバケツ式、一頭ずつ |
| 血統 | 全頭に血統書と名前があり、名前で呼ぶ。**40年前に導入した20頭以来、外部から牛を入れていない。**すべてその子孫 |
| 繁殖 | 人工授精。ジャージーの精液はほとんどアメリカからの輸入。性判別精液（約90%がメス）を上位の牛に、下位の牛には黒毛和牛を交配 |
| 健康管理 | **福井県で最も獣医を呼ばない。**「今年まだ2回しか呼んでいない」 |
| 後継者 | **6番目の子（27歳）**が6年間ともに従事。後継者は決まっている |

**FACT｜季節と品質**

- 乳脂肪率は**約5.0%**。一般の紙パックは3.6〜3.7%。「**1%以上違うと、誰が飲んでも濃いと分かる**」。
- 牛乳は純白ではなく**薄いクリーム色**。**放牧が始まって青草を食べ始めるとクリーム色に変わる。**
- **夏は乳脂肪率がやや下がり、冬は水を飲む量が少ない分だけ濃くなる。**

**FACT｜気候対応**

- 猛暑のため**夜間放牧**に切り替えている。夜の搾乳後**20時に放牧に出し、朝6時に戻す**。昼は牛舎。「夏バテ知らずで絶好調」。
- 冬は**積雪2m**で放牧できず、乾草を給与する。「牛に運動の要求はない。くっちゃ寝が大好き」。
- 牧草は永年牧草（西洋牧草）で夏の暑さに弱い。近年は**エノコログサ、メヒシバなど日本在来の「雑草」**が生えるようになり、これを牛が食べる。雨が降らなくても伸びるため、**夏の放牧を休まずに済むようになった。**

## 4-3. 経営の考え方

**FACT**

- ジャージーは乳量が少ない（年6000kg以上、日20L以上）。ホルスタインは年1万kg。「**同じ一頭を飼うならホルスタインのほうが効率的**」であり、「**メーカーはジャージーだからといって高くは買ってくれない**」。
- したがって「**販売までしないと意味がない**」。最初からその前提で、**「松本牧場」ではなく「ラブリー牧場」という名前で活動している。「ネーミングは大事です」。**
- **「6次産業化」という言葉がない時代から**生産・加工・販売を統合してきた。「6次産業化をやっているとしたら全国一じゃないか」。
- **国の政策は規模拡大に補助金を出す方向だが、それとは逆に頭数を減らしている。**
- 放牧を選ぶ理由として、消費者の期待との一致が語られた。「**都会生まれの人間にとって、牧場とは放牧なんです。牛舎に繋がれっぱなしで飼料を飲んでいるなんて誰も思っていない**」「そういう飼い方をしていると、お客さんに対して自慢できる、見せてあげられる牧場になる」。

## 4-4. 体験プログラム

**FACT**

- **10人以上集まれば開催。**内容は**放牧地で牛を捕まえる、乳搾り、バター作り**。出来たてのバターを自家製パンにつけ、**牛乳は飲み放題。料金2000円。**
- **約2時間**かけて牧場の考え方を説明する。「初めは2000円が高いと言われるが、終わったら『これだけやってもらえて2000円は安い』と言われる」。
- 小学校や地域クラブなど、**毎年来る団体もある。**
- **「酪農教育ファーム」**という全国組織に加盟している。**福井県で加盟しているのは同牧場のみ。**
- かつては乗馬体験も行っていたが、馬がいなくなり中止。
- 視察者側から、**体験した子どもと体験していない子どもでは食への認識が明確に変わる**という調査の知見が共有された。「生産者と牛との関係を見せることが大事。紙パックしか見ていないのとは全然違う」。

## 4-5. 福井県の酪農の現状（重要）

**FACT**

- **福井県の酪農家は、かつて100軒以上あったが、現在15軒。**
- **福井県内に牛乳工場がない。**生乳を**石川県まで運び、製品にして運び戻している。**「全くエコじゃない」。
- 減少の要因として、**後継者不足と高齢化**、および**集落近接地における糞尿・臭気の苦情**が挙げられた。「後継者に移る時にもうやめて、自分の代で辞めていくというのが多い」。
- 同牧場自身も**牛乳が売れなくなっている。**委託加工していた工場が大工場に作り替えられ、**紙パック専用となって原料乳の加工を受けてもらえなくなった。**牛乳配達も継続できなくなり、現在は自店の原料として使用している。
- チーズは「勉強したが、やればやるほど奥が深く手がついていない」。ヨーグルトは、委託先の大型タンクに対して自社のロットが小さすぎて受けてもらえない。**自家消費分のみ製造し、販売はしていない。**

## 4-6. 観察と示唆

**OBSERVATION** — この牧場は、**放牧・ジャージー種・6次産業化という3点すべてで県内ほぼ唯一の存在**である。しかもそれは理念先行ではなく、「ジャージーは効率が悪く、メーカーが高く買わない。だから自分で売るしかない」という**経済的必然から導かれた統合**である。

**OBSERVATION** — 16頭の乳で20名を雇用しているという事実は、**生乳出荷ではなく加工・販売まで行うことで、頭数あたりの経済規模が大きく変わる**ことを示す。これは9月1日に確認した「一次産品のままでは価格が上がらない、6次産業化まで進めないとビジネスにならない」という議論の、酪農における実例である。

**OBSERVATION** — 一方、**加工の外部依存が構造的な弱点**として露呈している。委託先の大工場化により原料乳の加工を断られ、県内には牛乳工場がない。**6次産業化を志向しても、その「2次」の部分を域内で担保できていない。**

**INSIGHT** — 大野・勝山における酪農は、**産業としては縮小の最終局面にあるが、体験・教育コンテンツとしての価値は逆に希少化している。**県内唯一の放牧・酪農教育ファーム加盟という条件は、産業規模の小ささゆえに独占的である。ただし、これは産業の衰退を前提とした価値であり、**牧場そのものの経営が続かなければ成立しない。**加工受託先の喪失は、この前提を直接脅かしている。

**NEXT QUESTION**

- 体験プログラムの年間開催回数、参加者数、収益寄与。
- 少人数（1〜2組）での受入可否と、その場合の料金設定。視察時に「何組かずつなら喜ばれる」との反応があった。
- 六呂師の県営牧場・スキー場運営会社（羊の飼育開始）との連携可能性。
- 後継者（27歳）の事業構想。

## 5-2. 水と米

**FACT｜発見された江戸期の井戸**

- **令和3年（3〜4年前）、座敷の床下から江戸時代の井戸が発見された。**シロアリ対策で床下を直した際、石で封印されているのを大工が開けたところ井戸だった。**親も祖父も、言い伝えも資料も残していなかった。**
- **笏谷石**（しゃくだにいし）の石組み。福井の石で**現在は採掘禁止**。**濡れると青くなる**のが特徴で、封印に使われていた石をカットし、表面を見せられるようにしている。
- 井戸の**水位は地表から約3m。**この水は大野の生活用水と同じ。
- **水温は年間ほぼ13.5〜14度。**「夏冷たく冬暖かい水というのが地下水の特徴」。
- 雪解け水が多い時期は水位が上がる。先週の大雨（警戒レベル5）の際も上がった。**季節による変動がある。**
- 飲用の水質検査も実施済み。

**FACT｜大野の地下水構造**

- **大野市街は約7000世帯。ほとんどが自分の敷地内の井戸ポンプで汲み上げており、上水道は簡易水道しかない。**
- **醸造用の井戸は地下40〜50m。**（南部酒造場は50m）
- **一般家庭は地下10〜20m。**山側では30〜40m掘る必要がある。
- **地下約30mに粘土層**があり、その下は被圧地下水。
- **岐阜県の山沿いに降った雨などが、扇状地の末端で湧き出る**構造。
- 「大野市は**直径20キロのボウル**のようなもの。ストローを突っ込めばいくらでも水が吸える」と説明された。
- **地下水は1日約30cm移動する**ことが大学の研究で分かっている。
- **日本百名水に選定された際、NHKが水質を調査した。百名水のうち80数か所を調べて平均値を算出したところ、大野の水がその平均値とぴたりと一致した。**「日本の模範的な平均値」と説明された。

**FACT｜仕込み水と酒米**

- 仕込み水は**地下50mから汲み上げる伏流水**。**霊峰白山から連なる山々が蓄えた水**であり、同社はこれを**「山の恵み」**と呼んでいる。
- 酒米は**地元大野産の五百万石**（**全国屈指の生産量**）と**兵庫県産山田錦**。
- 精米は**4割から7割近くまで**削る。
- **目標は県産米100%。**地元で山田錦を作ってもらう取り組みを進めている。「地元の個性をしっかり考え方に寄せていこうというのが今やっている最中」。

## 5-3. 製法と商品開発

**FACT**

- 主力は**純米酒**。**新酒から30年ものの古酒まで**展開する。
- **温度管理**：もろみは**1日0.5℃以上変化させない**のが一般的なセオリー。0.5℃以上変化させると酵母が死ぬか休眠する。同社は**目標温度より1度ほど低い温度のブライン**を走らせて制御している（「他社さんはそこまでしない」）。
- **古酒**：**100年熟成の研究**を行っている。現在最も古いもので40年。20年物の「花垣古酒」は**コーヒーほどの色の濃さ**になる。**古酒蔵を継続して作っているところは日本で10か所程度。**
  - 背景として「**食管法の時代までは酒は税務署の免許制で早く売らねばならず、紹興酒のように長く寝かせて美味しいという文化が日本に育たなかった**」と説明された。
  - 「**焼酎の古酒は寝かせると味が丸くなるが化けない。日本酒はアミノ酸も糖分も多く含むので、寝かせると化ける。いかに化けるかが面白い**」。
- **樽熟成酒**：社長は白山山麓のワイナリーの製造責任者を務めた経験があり、ヨーロッパ研修も重ねた。**フレンチオーク（アリエ産）の樽で1年熟成。**純米大吟醸の華やかな香りとぶつかると想像したが、意外に馴染んだ。
- **梅酒**：福井県産の梅を日本酒で漬ける。**青梅ではなく完熟梅**を使うため、酸味ではなく果実の味になる。3年・7年・10年もの。人気商品。
- **搾りたて（0年）は予約受注のみ。**酒販店が事前に数量を確保し、絞った時点で予約分で完売する。

# 6. 醤油 — 野村醤油

## 6-1. 全国的な希少性（重要）

**FACT**

- **福井県内の醤油メーカーは18社。**そのうち**麹づくりから最終の醤油まで一貫して作っているのは野村醤油のみ（18分の1）。**
- **18分の3**は野村醤油から**麹を買って**自社で仕込む。
- **残る18分の14**は、**搾った後の生醤油を買って**その後の工程を行う。
- **全国各地でも、麹を作るメーカーはほとんどなくなっている。**
- 麹づくりは**冬の間だけ**行う。

**FACT｜他社からの受託** — 大豆から醤油を作れるメーカーが少ないため、各地から「自分たちの大豆で醤油を作れませんか」という依頼が来る。福井県池田町の道の駅の醤油、坂井市の施設の醤油なども同社が製造している。

## 6-2. 大野という立地の条件

**FACT** — 大野で醤油を造る条件として、以下が挙げられた。

- 「**幸いですね、美味しい水が安価に手に入りますので、仕込み水に困ることもない**」
- 「**盆地特有で、冬はしっかりと雪も降りますし、夏はこういう感じでしっかり暑い。**これが醤油を作る工程で、**温度管理をしなくても非常にいい醤油ができる**」

**FACT｜井戸の深さ** — 野村醤油の井戸は**地下50m**。南部酒造場も50m。一般家庭は10〜20m。「**水の層が全然違うので、少し違うような味がする**」。
また「**上の方（山側）の水はあまり良くない。どちらかというと下の方の水のほうが美味しい感じがする**」という見解が示された。ただし「**街の中はそんなに変わらない**」とも述べられた。

## 6-3. 製法

**FACT｜原料** — **大豆・小麦・塩・麹**。塩は粗塩を使用。

**FACT｜麹の種類** — 醤油には**緑色または黄色**の麹菌を用いる（**タンパク質の分解が得意**）。焼酎は黒麹（米・麦の分解が得意）、味噌は米に黄色または白の麹。「よく溶けるものがいい醤油になるので、それに合うように菌を選ぶ」。

**FACT｜櫂入れ（かいいれ）** — もろみを撹拌する作業。**目的は2つ**。

1. **空気を入れて発酵を促す**（もろみの中では微生物が発酵という仕事をしている）
2. **均一にかき混ぜる**

棒の先に羽根状のものが付いた道具を使う。空気を入れる場合は先を一旦もろみから浮かせて落とし、上のもろみを下に入れる。かき混ぜる場合は逆に、下のものを持ち上げて上に出す。頻度は、暑い時期は表面に白い膜が出ないよう頻繁に、それ以外は「悪く言うと春までほったらかし」程度。

**FACT｜ふろしき搾り**

- 風呂敷を広げ、下に木枠を置き、**もろみを乗せて平らに均し、畳む。**これを繰り返す。
- **1日かけて約800枚を積む。**一度に大量に積むと崩れて倒れるため、**1日かけてゆっくり水分（塩量）を出しながら**積み上げる。
- 積み重ねると自重で布の間から醤油がじわじわと出る。醤油が出た部分は固まってくるので、そこにまた乗せる。
- 800枚積み終わると醤油が出る。翌日、出が止まったところで**上から重しを乗せる**とまた出る。それも止まったら**圧力をかけて押し込む。**
- **約1週間かけて、約2000リットル**の醤油が得られる。

**FACT｜醤油粕** — 搾った後に板状の醤油粕が出る。**現在は田畑の肥料として希望者に提供している。**かつては牛・豚の飼料だった。「美味しい部分はほぼ醤油に出てしまい、パサパサしてそんなに美味しくない」ため食用にはしていない。

**FACT｜大豆の種類** — 日本の**大豆自給率は7%、93%が輸入**。同社は**半分ほどを地元産・国産大豆**でまかなっている。

- **脱脂加工大豆**（油を搾った後の大豆）：市販醤油の多くの原料。**旨味が強く、すっきりした醤油**になる。「油をしっかり取ってから醤油を作るのは、SDGs的にも非常に良い作り方」と説明された。
- **丸大豆**：油分が残るため**まろやかだが甘みは抑えられる。**

**FACT｜味噌との違い** — 味噌は米麹と蒸した大豆を仕込む。水を絞っても醤油は出てこない。上部に出る**味噌溜まりが一番美味しい**（香りと旨味がある）。

## 6-4. 体験プログラム

**FACT｜経緯と目的**

**FACT｜プログラムの流れ**

2. **原料と製法の学習**（醤油がどのように作られるか）
3. **味比べ**（工程の違う4種類）

**FACT｜味比べの4種**

| 4 | **甘い醤油**（火入れ時に甘味を加える）。「**九州と一緒で、北陸の甘い醤油を作っている**」 |

**FACT｜現在の運営状況（制約）**

# 7. 米 — 無農薬・無化学肥料の栽培

## 7-1. 転換の経緯

**FACT**

- 生産者は**百姓の長男**。栽培学・土壌学の専門教育は受けていないと自ら述べた。
- 転換のきっかけは**事故**である。カメムシ用の農薬（粉剤）を散布していた際、**子どもがホースの水を持って行ったところ粉を吸い込み、真っ青になって倒れた。**「これはあかん、散布だけでなく他の農薬全般すべてダメだ」と考え、やめることにした。
- 当時は父も存命で周囲の理解も得られず、**当初は密かに黙って続けていた。**
- **3反（100m×30m）から始め、現在は約2.6ヘクタール。**約20年が経過している。
- 独学とネットの情報から始め、NHKで**木村秋則氏（「奇跡のリンゴ」）**を知って感銘を受けた。研修・講習会に北海道から兵庫まで参加した。
- そのなかで、**農薬だけでなく化学肥料も、さらに畜産系の有機堆肥も使わない**という考え方に出会い、それを採用した。

## 7-2. 収量という現実

**FACT**

| 項目 | 内容 |
| :-- | :-- |
| 慣行栽培 | 10俵程度 |
| 初年度 | 6俵取れた |
| 3年目 | **1俵**。田んぼによっては100m×30mで**0.5俵**しか取れなかった |
| 現在 | **3俵程度**まで回復 |
| 本人の評価 | 「全国平均で6俵と言われるので、まだ伸びしろはある」 |

**FACT** — 技術者からは「養分を入れずに取ろうとしている。**取れた分だけ入れなければダメだ**」と言われた。それに対し、収量が3俵まで戻ったことを示して反論した経緯が語られた。

**FACT｜土壌回復の考え方** — 「**50年、60年と化学肥料を入れてきたのなら、回復にも50年、60年かかる。1年、2年で取り戻せるわけがない。**それも自分の手ではなく、**稲や雑草の力を借りる**」。

**FACT｜雑草観** — 「雑草を全部除去してこれだけを作ればいいと思っても、自然界のなかではそれができない。**雑草をなくすことは自然界の一つの種を滅することになる。**お互いが共存して初めて成り立つ」。

## 7-3. 水・土・気候

**FACT｜水（重要）**

- **醸造事業者が地下水を汲み上げるのに対し、この生産者は「上の方の水」＝表流水を使う。**
- 九頭竜川を堰き止めて引いた用水である。九頭竜川は急流で落差が大きいため、**北陸電力が発電に用い、発電後に必ず水路へ流す**構造になっている。
- 圃場は**九頭竜川と真名川の合流地点に近い。**
- 「下流の坂井郡や奥越の方に行くと、**上流で使った水を河川へ流し、それをまた使う。**悪い言葉で言えば**排水が凝縮したような水**が流れている。ただし反面、栄養分も豊富で、福井県の穀倉地帯という名前も上がっている」
- 「**ここは上流から来た水が、何も使われていないそのままの状態で入る。清流の水をイメージしていただければいい。ミネラルの部分がかなり入っていると私は思っている**」
- **ただし「別に水質分析をしたわけではない」と本人が明言している。**

**FACT｜土**

- 九頭竜川と真名川（主に真名川）の**扇状地の沖積地**。表土は20cm程度で、その下は砂利。「大きな石がごろごろ出てくる。とても田んぼに適しているとは思いもつかない場所」。
- 加えて**経ヶ岳の噴火跡**があり、**沖積土と火山灰土が入り混じった土**になっている。
- 場所により「粘土っぽい土」「砂質土」が**点在している。**

**FACT｜気候** — 「以前はこの盆地形状で寒暖差があり、米の色も味も良いと言われていた。しかし**近年の暑さのなかでは、自信を持って寒暖差があるとは言えなくなった。**今日でも30度以上ある。稲もへばっているのではないか」。

## 7-4. 品種

## 7-6. 栽培管理の工夫

**FACT**

- **除草剤は不使用。機械で処理する。**除草剤による風の草への薬害も避けている。
- **藁は田んぼにそのまま置く。これが唯一の有機物として循環する。**表面に置くだけでは腐植しにくいため、ロータリーではなく**リストハローで天地返し**を行い、藁を土中に鋤き込んで腐植を促す。
- **クサヒエ**（実が米に似た雑草）は、色彩選別機でも除去しきれず、混入すると黒い粒としてクレームになる。そのため**収穫前に田んぼに入って全部手取りする。**
- **畜産系の堆肥は牛糞・豚糞を問わず一切使用しない。**
- 圃場を転々とせず、**同じ田んぼに固定して作り続ける。**訪問した圃場は10年ほど固定している。

**FACT｜隣接圃場からの農薬流入対策** — 隣接する田は慣行栽培であるため、以下の対策を取っている。

1. **田んぼを6枚ほどまとめて**作付けし、外周からの影響を減らす
2. **畦幅を、通常30cmのところ60〜70cmに広げる**
3. **上流の田との間に60cmほど植えない空間を設け、溝を掘る。**上から流れてくる養分混じりの水を**直接排水へ落とす**

**FACT｜水と山と海** — 「**水があるのは山があるおかげ**なので、山も大切にしなければならない。反対に、田んぼから流れた水は最後は海に流れるので、**海にも迷惑がかかる。**だから水を汚さないでおく。山には木を植える。そういう水をいただいているということを大切にしている」。

## 7-7. 観察と示唆

**OBSERVATION｜収量の実数が持つ意味** — 慣行10俵に対し1〜3俵という数字は、**この栽培方法が「こだわり」ではなく「経済的な断念を伴う選択」である**ことを示す。9月1日の酢蔵の自社栽培（「盆栽農業」と自称）と同様、**大野で確認された高付加価値志向の農業は、いずれも収量を大幅に犠牲にしている。**

**OBSERVATION｜水系の位置づけ** — この生産者が地下水ではなく表流水を使い、しかも「**上流で誰も使っていない水がそのまま入る**」という位置にあることは、**大野の農業用水が水系の最上流部に位置する**という地理的条件を示す。ただし「ミネラルが多いと思う」は本人が明言するとおり**未分析の主観**であり、FACTとして扱えるのは水の由来と経路のみである。

**INSIGHT** — 大野の米は、9月1日に酒・酢の原料として、9月2日には自然栽培の対象として確認された。**しかし両者の水は異なる。**醸造は深層地下水、稲作は表流水である。「水が米を育て、その米が酒と酢になる」という連鎖は、**水源としては連続していないが、水系としては連続している。**この区別は、次段でストーリーを構成する際に決定的に重要になる。

# 8. 水 — 9月2日に判明した重層構造

本章は、9月1日レポート第4章の内容を更新するものである。

## 8-1. 用途による水の使い分け

**FACT** — 9月2日に確認された、大野における水利用の層。

| 用途 | 水源 | 深さ・経路 |
| :-- | :-- | :-- |
| **醸造（酒・醤油）** | 深層地下水 | **地下40〜50m。**粘土層（地下約30m）の下の被圧地下水 |
| **一般家庭** | 浅層地下水 | **地下10〜20m。**山側では30〜40m。約7000世帯が自家の井戸ポンプで汲み上げ、上水道は簡易水道のみ |
| **稲作** | **表流水** | 九頭竜川を堰き止めて引いた用水。北陸電力の発電後に放流されたもの |
| **工業** | 地下水 | 電子部品工場（9月1日確認）。大量取水 |
| **市街の清水** | 湧水 | 地表から約3mの水位（9月2日、酒蔵の井戸で確認） |

**FACT｜涵養構造** — **岐阜県の山沿いに降った雨などが、扇状地の末端で湧き出る。**「大野市は直径20キロのボウルのようなもの」。**地下水は1日約30cm移動する**ことが大学の研究で判明している。

**FACT｜水温** — 深層地下水は**年間ほぼ13.5〜14度**（酒蔵の井戸）。9月1日に市街の清水で確認された値は**7月で約16度**であった。**深さによって水温が異なる。**

**FACT｜季節変動** — 雪解け水が多い時期は水位が上がる。大雨（警戒レベル5）の際にも上昇した。

## 8-2. 水質と味の差について（更新）

**FACT｜9月2日に得られた新しい見解**

- 野村醤油：「**（醸造用の50mと一般家庭の10〜20mでは）水の層が全然違うので、少し違うような味がする**」
- 野村醤油：「**上の方（山側）の水はあまり良くない。どちらかというと下の方の水のほうが美味しい感じがする**」。ただし「**街の中はそんなに変わらない**」
- 南部酒造場：**日本百名水選定時のNHKによる調査で、百名水のうち80数か所の平均値を出したところ、大野の水がその平均値と一致した。**「日本の模範的な平均値」
- 米生産者：表流水について「**ミネラルの部分がかなり入っていると私は思っている。別に水質分析をしたわけではない**」

**OBSERVATION** — 9月1日には、地域側が「同じ地下水はなかなか難しい」「基本は全部軟水」と述べ、酢の生産者は「大野の水しか使ったことがないので分からない」と述べた。9月2日には、**深さの違いによる差については「違う味がする」という見解が得られた**が、いずれも**主観であり、測定データによる裏づけはない。**

> **更新後の整理**
> - **水源による味の差**：依然として未検証。地域側の見解は一致していない。
> - **深さによる差**：「違いがある」という見解が9月2日に得られた。ただし未測定。
> - **市街地内の水平方向の差**：「そんなに変わらない」という見解（野村醤油）。
> - **大野の水の全国的位置づけ**：「日本の百名水の平均値」という調査結果がある。これは**「特異である」ではなく「標準的である」という意味**であり、差別化の根拠としては慎重な扱いを要する。

**INSIGHT** — 「百名水の平均値」という事実は、**水の希少性を主張する方向とは逆に働く可能性がある。**一方で「日本の水の模範」という語り方は成立しうる。いずれにせよ、**大野の水の価値は成分の特異性ではなく、（a）量が潤沢であること、（b）安価に得られること、（c）多層に使い分けられていること、に求めるほうが記録に忠実である。**

# 11. 9月1日レポートで保留した論点への回答

9月1日レポートで「9月2日の記録と突合する」とした論点について、現時点の結論を示す。

## 11-1. 「大野の発酵文化」という括りは成立するか

**9月1日時点の状態** — 酢の生産者が「酢に地域性は薄い」「大野の酢の歴史は特にない」と明言したため、この括りは**外部者の編集仮説にとどまる**とした。

**9月2日の結果**

| 業種 | 地域固有性の根拠 | 判定 |
| :-- | :-- | :-- |
| **酢** | 生産者本人が否定。「酢は地域性が薄い」 | **根拠なし** |
| **醤油** | 「美味しい水が**安価に**手に入る」「**盆地特有で冬は雪、夏は暑い。だから温度管理をしなくても良い醤油ができる**」。県内18社中、麹から一貫するのは1社のみ | **根拠あり（強い）** |
| **酒** | 地元産五百万石が全国屈指の生産量。地下50mの伏流水を「山の恵み」と呼ぶ。県産米100%を目標 | **根拠あり** |

**現時点の結論** — 「大野の発酵文化」という括りは、**醤油と酒を軸にすれば成立する。酢はその内側に置けるが、酢を根拠にすることはできない。**酢の価値は「大野らしさ」ではなく「製法の希少性（国内約1%の静置発酵）と原料の質」にある、というのが生産者本人の認識であり、これを尊重すべきである。

なお、醤油と酒に共通するのは「**水と気候が、コストや設備の代替として機能している**」という論理である。これは「大野の水は美味しい」という情緒的な主張とは異なる、**経済的に検証可能な主張**である。

## 11-2. 3業種の水は同一水系か

**9月2日の結果** — **醸造3業種（酢・酒・醤油）は、いずれも大野市内の地下水を用いる。**酒蔵と醤油蔵はともに**地下50m**の深層地下水であることが確認された。酢蔵の井戸の深さは記録から確認できていない。

一方、**稲作は地下水ではなく表流水**（九頭竜川からの用水）である。**原料米を育てる水と、それを醸す水は、別の水である。**

**現時点の結論** — 「水 → 米 → 発酵」という連鎖は、**同一の水源による連続ではない。**ただし、山に降った雨・雪が、一方は河川となって農業用水に、一方は伏流して扇状地末端の地下水になる、という**同一の水系における分岐**として説明できる。この区別を曖昧にしたまま「同じ水が米も酒も作る」と語ることは、記録に反する。

## 11-3. 水源ごとの味の差はあるか

**9月2日の結果** — 新たに以下が得られた。

- 深さの違い（50m対10〜20m）については「**違う味がする**」（醤油蔵）
- 山側と平地側については「**上の方の水はあまり良くない、下の方が美味しい**」（醤油蔵、主観）
- 市街地内では「**そんなに変わらない**」（醤油蔵）
- 大野の水は**日本百名水の平均値と一致**（NHK調査）

**現時点の結論** — **依然として測定データによる裏づけはない。**9月1日の「同じ地下水はなかなか難しい」「基本は全部軟水」という見解と、9月2日の「層が違えば味が違う」という見解は矛盾しない（前者は同一層内、後者は層間の比較である可能性が高い）。

**したがって、水源別の飲み比べを前提とする企画は、依然として根拠を持たない。**ただし**深さ別の比較**であれば、差が存在する可能性は9月2日にやや高まった。検証の設計は「水源別」ではなく「**深度別**」を優先すべきである。

# 12. 現時点の示唆（9月2日分）

9月1日レポートの Insight 1〜6 に対する追加である。

## Insight 7｜「水が共通基盤」は、水系のレベルで正しく、水源のレベルでは正しくない

大野の水は、深層地下水（醸造）、浅層地下水（生活）、表流水（農業）、湧水（市街の清水）に分かれて使われている。**共通しているのは水そのものではなく、山に降った雨と雪という起点である。**この精度で語らなければ、生産者に否定される。

## Insight 8｜地域固有性は「水が美味しい」ではなく「水と気候がコストを肩代わりしている」ことにある

醤油蔵の「**美味しい水が安価に手に入る**」「**盆地特有の気候だから温度管理をしなくても良い醤油ができる**」という説明が、当日最も具体的な地域固有性の記述であった。これは情緒ではなく**生産条件**の話であり、他地域との比較が可能で、検証にも耐える。

## Insight 9｜受入キャパシティは「望ましい規模」ではなく「物理的上限」である

酒蔵20人／6人、牧場10人以上、酢蔵4.5人体制。**少人数型は選好ではなく制約である。**さらに、その少人数ですら現状では受けきれず、酒蔵・醤油蔵はいずれも停止している。**体験事業の設計は、需要ではなく供給側の担い手確保から始める必要がある。**

## Insight 10｜大野の高付加価値化は、生産の努力ではなく制度と基盤の不足で止まっている

有機JAS認証の書類ハードル（9/1）、自家採種の25年制限、肥料入りの育苗床土、県内に牛乳工場がないこと、小ロットを受けない加工工場。**確認された制約は、いずれも生産者個人の努力の外側にある。**「もっと頑張れ」では動かない領域に課題がある。

## Insight 11｜「水の里」は、まず物理的に見えるようにする段階にある

「水の里と言っている割に水が見えない」「側溝に全部蓋がしてある」「発見された井戸をコースに入れるべきだ」という指摘は、編集やストーリー以前の、**可視性の問題**を示している。9月1日の「資源は点として存在する」という観察は、水においては「**点としてすら見えていない**」という段階にある。

> **本レポートの結論の範囲**
> 9月1日レポートと同じく、**「水が複数資源をつなぐ有力な共通軸ではないか」**という水準までを提示する。9月2日の記録は、この仮説を**支持すると同時に、その語り方に強い制約を課した。**すなわち、水を軸にするならば「同一の水」ではなく「**同一の水系における分岐**」として、また「美味しい水」ではなく「**潤沢で安価な水と、それを補完する気候**」として語らなければならない。
> 構想としての結論づけは行わない。**視察レポート（9/1・9/2）→ 統合 → 分析 → コンセプト開発 → 構想** という順序を維持する。

## B-4. 次段に引き継ぐ制約条件

9月1日レポートで挙げた2点を更新し、5点として引き継ぐ。

1. **水源ごとの味の差は、依然として未検証である。**検証の設計は「水源別」ではなく「**深度別**」を優先する。
2. **「大野の発酵文化」は、醤油と酒を軸にすれば成立する。酢を根拠にすることはできない**（生産者本人が地域性を否定している）。
3. **醸造用水（地下40〜50m）と農業用水（九頭竜川の表流水）は別の水である。**「同じ水が米も酒も作る」とは言えない。「同一水系における分岐」として語る必要がある。
4. **受入キャパシティは物理的な上限である。**酒蔵20人／宿泊研修6人、牧場10人以上、酢蔵4.5人体制。さらに酒蔵・醤油蔵とも現在は停止しており、**再開には担い手の確保と、それを支える価格設定が前提となる。**
5. **大野の水は「日本百名水の平均値」と一致する。**成分の特異性ではなく、**潤沢さ・安価さ・使い分けの多層性**に価値を求めるほうが、記録に忠実である。
