# 01. Executive Verdict

## **判定：CONDITIONAL GO ― ただし、初期構想の中核（分散型ホテル）は HOLD**

正確には、対象を分解した上での複合判定である。**「大野市×ENOWA」というプロジェクト全体にGOを出すが、提案書Vol1/Vol2が中核に据えた「分散型高付加価値ホテル」にはGOを出さない。**

| 対象 | 判定 | 条件 |
| :-- | :-- | :-- |
| **地域との関係構築・体験の商品化** | **GO** | 即時着手。投資規模 数百万円 |
| **水質の科学検証（WATER INDEX）** | **GO** | 最優先。これが他の全施策の前提 |
| **城下町ガイド・発酵体験の商品化** | **CONDITIONAL GO** | 受入側の書面合意が前提 |
| **WATER PAIRING DINNER** | **CONDITIONAL GO** | PoCで支払意向を検証してから |
| **分散型ホテル（4〜6室）** | **HOLD** | Gate 2の全基準を満たすまで投資しない |
| **WATER CUP／飲み比べ企画** | **HOLD** | 前提（水源別の差）が未証明 |
| **Water Summit／海外連携** | **DROP** | 現時点では事業性・優先度ともに低い |
| **「WATER DRIVEN DESTINATION」という概念の対外発表** | **PIVOT** | 現行の定義のままでは生産者に否定される |

そして最も重要な判定として——

> **民間単独投資としての宿泊事業は、現時点で NO-GO である。**
> これは本FSの独自見解ではない。**提案書Vol2自身が「単独投資では回収年数が10年を超え事業化が困難」と明記している。**
> すなわち本件は、提案時点で既に **Subsidy-dependent（補助金依存）** であることが自己申告されている。

# 02. Why ― 判定の理由（5点）

### 理由1｜提案書が中核に据えた指標「宿泊比率4%」は、指標として成立していない

提案書Vol1・Vol2はいずれも「年間入込214万人に対し宿泊8.5万人＝宿泊比率4%」という**構造的ギャップ**を出発点としている。しかしこの2つの数値は**単位も母集団も異なる。**入込客数は通常「延べ人回」（1人が3施設に立ち寄れば3カウント）であり、宿泊客数は「延べ宿泊者数」または「実人数」である。

**分子と分母が対応していない比率は、転換率として解釈できない。**「4%を上げる」という目標設定自体が、測定不能な目標である。〔Evidence: A'（提案書記載）＋F（本FSによる単位検証）〕

これは些細な指摘ではない。**プロジェクト全体の問題設定がこの1つの数字に依存している。**

### 理由2｜WATER DRIVENの中核仮説2つが、現地で否定されている

| 仮説 | 現地での確認結果 |
| :-- | :-- |
| 水源ごとに味の差がある | 地域側「**同じ地下水はなかなか難しい**」「**基本は全部軟水**」。酢の生産者「**大野の水しか使ったことがないので比較ができない。正直に言うと分からない**」〔E：9/1〕 |
| 同じ水が米・酒・酢・醤油をつくる | **醸造は地下40〜50m、生活用水は10〜20m、稲作は地下水ではなく九頭竜川の表流水**〔E：9/2〕。水源としては連続していない |
| 大野の水は特異である | 日本百名水選定時の調査で「**百名水の平均値とぴたり一致**」＝標準的であることが特徴〔E：9/2〕 |

提案書Vol1は「**Water dictates everything.（水が味のすべてを決める）**」と宣言している。**この主張を、現地の生産者は支持していない。**コンセプトの根幹が、当事者に否定されている状態でブランドを立ち上げることはできない。

### 理由3｜供給制約が需要制約より厳しく、しかも現在すでに停止している

提案書は需要側（誰が来るか、いくら払うか）を論じるが、**供給側（誰が受け入れるか）の実数を検証していない。**視察で判明した実数は以下である。〔すべて E：9/1・9/2〕

| 事業者 | 受入上限 | 現状 |
| :-- | :-- | :-- |
| 南部酒造場（酒） | 説明20名／回、**宿泊研修は3名×2班＝6名が安全管理上の上限** | **一旦停止中**（「かなりエネルギーがかかる」） |
| 野村醤油（醤油） | 記録に明示なし | **停止中**（人手不足＋夏季の熱中症対策） |
| 河原酢造（酢） | — | **4.5人体制**（社員2＋パート1＋社長） |
| ラブリー牧場（酪農） | 10名以上で開催 | 実施中 |

**需要不足ではなく供給側の負荷が理由で停止している。**すなわち、集客に成功するほど、この制約は悪化する。

### 理由4｜経済性は「規模」で決まるが、提案書の推奨規模は最も不利な水準にある

本FSのボトムアップP&L（後述）によれば、提案書の自己申告値（ADR 45,000円/人、2名1室）を用いても、EBITDA率は室数に強く依存する。

| 室数 | 想定人員 | 売上（稼働50%） | EBITDA | EBITDA率 |
| :-: | :-: | --: | --: | --: |
| **4室** | 7 FTE | 65.7百万円 | **4.5百万円** | **6.8%** |
| 6室 | 8 FTE | 98.5百万円 | 20.3百万円 | 20.6% |
| 10室 | 11 FTE | 164.2百万円 | 46.7百万円 | 28.4% |
| 15室 | 15 FTE | 246.4百万円 | 78.4百万円 | 31.8% |

〔F：本FSによる推定。前提は第12章に明示〕

提案書Vol2は「初期4〜6室」から始めるとしている。**しかし4室は、固定人件費に耐えられない。**「小さく始めてリスクを最小化する」という戦略は、**この事業形態では経済的に逆方向に働く。**リスクを下げるつもりの小規模化が、赤字リスクを上げている。

### 理由5｜提案書が最大リスクと認識しているものと、実際の最大リスクが一致していない

提案書Vol2は「民間単独投資を阻む3つの構造的リスク」として **① 初期CAPEX ② 冬季・気候 ③ 送客分断** を挙げる。本FSのPre-mortem分析では、致命的リスクの上位は以下となった。

| 順位 | 本FSの評価 | 提案書での扱い |
| :-: | :-- | :-- |
| 1 | **受入側が体験提供を続けられない** | **言及なし** |
| 2 | **ADR 4.5万円が実現しない（3万円で営業赤字）** | 根拠を示さず前提として使用 |
| 3 | 通年稼働率40%割れ | ②として認識 |
| 4 | 改修費超過 | ①として認識 |
| 5 | **運営人材を採用できない** | Vol2で市への要望として言及のみ |

**上位5つのうち3つ（1・2・5）が、提案書で検証されていない。**CAPEXは本FSの試算では最大のリスクではない（後述のとおり、CAPEX 20百万円/室までならBaseケースでIRR 7.4%が成立する）。**リスクの優先順位を誤ったまま、市に対してCAPEX支援を要求している。**

# 05. What Was Wrong ― 初期構想のうち、修正・撤回すべきもの

**遠慮なく記す。**これは提案の否定ではなく、提案を投資可能な水準に引き上げるための指摘である。

## 5-1. 撤回すべきもの（Retract）

### W1. 「Water dictates everything.（水が味のすべてを決める）」

**現地の生産者が明確に否定している。**酢の生産者は水と味の関係について「**正直に言うと分からない**」と述べ、地域側は水源別の識別を「**なかなか難しい**」「**基本は全部軟水**」としている。〔E：9/1〕

この一文をブランドメッセージに用いた場合、**最初の取材で生産者に否定されるリスクがある。**撤回し、後述の代替表現に置き換えるべきである。

### W2. 「宿泊比率4%からの脱却」という目標設定

理由1のとおり、指標として成立していない。**KPIから外すべきである。**代替指標は「**1人あたり域内消費額**」「**域内調達率**」など、単位が閉じているものにする。

### W3. 「アジア初『星空保護区』認定」という表記

9/2の現地説明では「**アーバン・ナイト・スカイプレイス**」認定と説明された。これはDarkSky Internationalの認定カテゴリとして「星空保護区（International Dark Sky Place）」とは**別のカテゴリ**である可能性が高い。〔要事実確認：第6章参照〕

**認定名称を正確に表記しない対外資料は、それ自体が信用リスクである。**

## 5-2. 過大評価されているもの（Overstated）

### W4. 「214万人の巨大なトップファネル」

入込客数は延べ人回であり、通過交通・道の駅立寄りを含む。**「214万人の集客力が既にある」という前提は、高単価宿泊需要の存在を何ら示さない。**道の駅でソフトクリームを買う客と、1泊9万円を払う客は、同じ母集団ではない。

### W5. 「小さく始めてリスクを最小化する」

理由4のとおり、**4室はEBITDA率6.8%で、固定人件費に耐えられない。**「小さく始める」ことが正しいのは**体験事業**であって、**宿泊事業ではない。**提案書はこの2つを同じロジックで扱っている。

### W6. 「関西大学＝知のアンカーによる公共性担保」

連携は実在する〔E：9/1・9/2〕が、確認できたのは**河川清掃、空き家改修、盆踊りの復活、OBの移住**であり、**地下水の定量評価を担う研究体制は確認できていない。**「学術的裏付け」を謳うのであれば、**どの研究室が、どの予算で、いつまでに、何を測るのか**が必要である。現状は期待の表明にとどまる。

### W7. 「4つの世界的概念を一つに統合できる稀有なポテンシャル」

Sextantio・Matera・Terra Dominicata・Heckfield Placeとの比較は、**いずれも大野より遥かに大きな観光市場・アクセス・資本を持つ事例である。**とくにHeckfield Placeはロンドンから約1時間、客室数45室規模の英国有数のカントリーハウスホテルであり、**4〜6室・冬季3ヶ月閉塞・最寄り空港から車1時間超の大野と、事業構造が根本的に異なる。**ベンチマークとしての参照は有効だが、**「同じことができる」という含意は成立しない。**

## 5-3. 根拠が不足しているもの（Unsupported）

### W8. 客単価 35,000〜45,000円の「根拠」

Vol1 p17は客単価の根拠として「ベース価値（古民家）＋ガストロノミー価値＋体験・ウェルネス価値」の積み上げを示す。**これは価格の構成要素の説明であって、支払意向の根拠ではない。**「なぜその金額を払うのか」ではなく「その金額を何に配分するか」を説明しているにすぎない。

### W9. 顧客構成比（中京45-55%／首都圏25-35%／インバウンド10-20%）

出典が示されていない。**日帰り客の発地構成を高単価宿泊客に外挿している場合、逆方向の誤りになる。**一般に、遠方からの客ほど宿泊率が高く単価も高い。中京圏が車で日帰りできることは、**宿泊需要にとっては不利な条件**でありうる。

### W10. 補助金の金額（県補助 上限6,000万円／観光庁 最大2億円）

制度名が明示されていない。〔要事実確認：第6章参照〕

## 5-4. 構造として問題があるもの（Structural）

### W11. Vol2は「ENOWAはリスクを取らない」という提案になっている

Vol2が市に求めている事項を並べると、以下になる。

- 物件の無償貸与・超低廉賃料
- 改修費の市負担（スモールコンセッション枠）
- 固定資産税の免除
- 大型補助金の申請伴走
- 道の駅からの専用シャトルの初期費用・運行補助の市負担
- 優先的な除雪動線の確約
- KDDI Location Analyzer等のODデータの無制限提供
- 運営人材の職員住宅・住居手当

**ハードのリスク、インフラのリスク、人材の住居リスクのすべてを市に移転する構成である。**その対価としてENOWAが提供するのは「ブランド・運営・送客」というソフトである。

この交換自体は成立しうる。**ただしその場合、ENOWAは「投資家」ではなく「運営受託者」である。**にもかかわらずVol1は「事業」として描かれており、**誰がリスクを取り、誰がリターンを得るのかが不明確である。**この曖昧さは、後の交渉で必ず破綻する。

### W12. 提案書自身が事業性を否定している

Vol2は明記している——「**単独投資では回収年数が10年を超え事業化が困難**」。

**これは提案書の弱点ではなく、むしろ誠実な記述である。**しかし帰結として、本件は**提案の時点で Subsidy-dependent であることが確定している。**投資委員会の観点では、この一文だけで「民間単独投資としてはNO-GO」の結論が出る。

## そもそも論（Q1〜Q5）

### Q1. 大野市は本当に Destination Development を必要としているのか

**判定：必要としているのは Destination Development ではなく、Industry Retention（産業の維持）である可能性が高い。**

視察で確認された事実を「深刻度×緊急度」で並べると、観光は最上位ではない。

| 課題 | 深刻度 | 緊急度 | 根拠（Evidence Level） |
| :-- | :-: | :-: | :-- |
| **産業の担い手消失** | 極高 | 極高 | 酪農100軒以上→15軒／県内に牛乳工場なし。醤油18社中、麹から一貫は1社のみ。酒蔵 県内53社→20数社、市内4→3社（E：9/2ヒアリング） |
| **若者流出と職種の欠落** | 極高 | 高 | 進学→就職→結婚で戻らない。製造業と公務員に偏り、事務系・IT・クリエイティブが乏しい（E：9/1） |
| **域内の加工基盤の欠落** | 高 | 高 | 生乳を石川県へ運び製品にして戻す。小ロットの委託加工先がない（E：9/2） |
| **高付加価値品が域内で流通しない** | 高 | 中 | 酢の98%が県外。市内販売は数店舗のみ（E：9/1・9/2） |
| 観光の滞在時間・宿泊比率 | 中 | 中 | 提案書の主張。ただし指標の定義に疑義（本FS A2） |

**含意**：観光は「解くべき課題」の第一位ではない。ただし、**観光は他の課題を解く手段になりうる**（域内消費の創出、職種の多様化、加工基盤の需要創出）。したがって問いは「観光をやるべきか」ではなく、「**観光を、産業維持の手段として設計できるか**」である。この転換は提案書には存在しない。

### Q2. 最大の課題は本当に「観光」なのか

**判定：No。最大の課題は「事業者の消滅」である。**

決定的な非対称性がある。**観光施設は後から作れるが、麹から一貫して醤油を作る蔵は、一度失われたら復元できない。**9/1で確認された酢蔵の事例がこれを実証している——5代目が戦時中に廃業した時点で地元の商売基盤は完全に消滅し、6代目が再興したが地元では二度と売れなかった。**失われた産業は、同じ場所には戻らない。**

現在、大野で同じ危機にあるのは、酪農（15軒）、麹から一貫の醤油（1社）、酒蔵（3社）である。**5年後に体験の相手がいなくなるリスクは、観光客が来ないリスクより高い。**

### Q3. 観光強化はその課題解決にどの程度寄与するのか

**定量的に見て、寄与は限定的である。**

本FSの試算では、6室・稼働50%の分散型ホテルが生む雇用は約8名、売上約1億円。市の年間宿泊客数に対する寄与は約3%。一方、市の人口は約3万人規模であり、**8名の雇用は人口動態を変えない。**

ただし、以下の3点では意味のある寄与が期待できる。
1. **職種の多様化**：料理・サービス・企画という、現在市内に乏しい職種が生まれる（9/1で確認された課題に直接対応）
2. **域内消費の受け皿**：酢の98%県外、醤油・酒の県外比率という構造に対し、**域内で高単価に売れる場**ができる
3. **加工需要の創出**：小ロットの乳製品・加工品に対する安定需要（六呂師ミルク工房等との接続可能性）

**含意**：観光の価値は「観光客数」ではなく「**域内経済の循環装置としての機能**」で評価すべきである。提案書のKPI（宿泊比率、ADR、稼働率）は、この価値を測れない。

### Q4. ENOWAが入ることが最適なのか

**部分的にYes。ただし「開発事業者」としてではなく「編集者・運営者」としてのみ。**

| 主体 | 得意 | 大野での適性 |
| :-- | :-- | :-- |
| **ENOWA** | 食の編集、体験設計、ブランド、運営 | **中核能力と課題が一致。**特に「素材はあるが売り方がない」という大野の課題（行政自身が認める）に直接対応 |
| DMO | 地域内調整、情報発信 | 単価を上げる能力は通常持たない |
| 旅行会社 | 送客 | 商品がなければ送客先がない |
| ホテル会社 | 運営、稼働管理 | 4-6室の規模では採算に乗らず参入しない |
| デベロッパー | 資金、開発 | この規模・立地では投資対象にならない |
| コンサル | 計画 | 運営を担わないため実装で落ちる |
| 行政単独 | 制度、インフラ | 9/2で行政自身が「ブランディングできていない、価格設定がうまくいかない」と明言 |

**結論**：「素材はあるが、価格をつけて売る能力がない」という課題に対し、ENOWAの能力は適合している。ただし**ハード投資の主体としてENOWAが最適である根拠はない。**Vol2が市に求めている内容（物件無償貸与、改修費負担、税免除、シャトル費用負担）は、裏返せば「ENOWAはハードのリスクを取らない」という宣言であり、それならば**ENOWAの役割はソフトに限定すべき**である。

### Q5. 「大野を高付加価値Destinationにする」という前提自体が妥当か

**この前提は、現時点では立証されていない。より妥当な前提は「大野を高付加価値な生産地にする」である。**

理由は3点。

1. **供給制約が需要制約より厳しい。**酒蔵は20名／宿泊研修6名が上限で現在停止中、醤油蔵も停止中、酢蔵は4.5人体制。「Destination」は多数の来訪者を前提とするが、**大野の受入能力は構造的に小さい。**

2. **大野の資源は「訪問」より「産品」に向いている可能性がある。**麹から一貫の醤油、静置発酵90日以上の酢、風穴熟成の酒、無農薬米は、いずれも**現地に来なくても価値が伝わる。**実際、酢は98%が県外で売れている。**「来てもらう」より「送り出す」ほうが、既に実証されている。**

3. **観光は手段であって目的ではない。**Q3のとおり、観光の意義は域内循環にある。ならば「Destination化」という目的設定は、手段と目的を取り違えている。

**代替の前提（本FSの提案）**
> 大野を「高付加価値な生産地」として確立し、**観光・体験はその生産地を体感させる補助手段**として位置づける。
> 宿泊は、その体験を成立させるために必要最小限の範囲でのみ検討する。

# 06. WATER DRIVEN 仮説の科学的検証

**本章が、コンセプトの根幹に対する最も厳しい検証である。**

## 6-1. 結論を先に示す

> **「大野の水だから食が美味しい」という主張には、査読論文による裏付けが存在しない。**
> より正確には——**硬度が50倍異なる水（軟水 vs 超硬水）で比較してさえ、かつおだしの官能総合評価に有意差は出ていない。**
> **同一地域の軟水同士の微差については、そもそも研究が存在しない。**

## 6-2. 証拠の強さは「硬度差の大きさ」に依存する

| 比較条件 | 証拠の強さ | 内容 |
| :-- | :-- | :-- |
| 軟水 vs 硬水（硬度差 数百mg/L以上） | **中〜強** | 成分溶出・物性の**機器測定差**は再現性が高い。**ただし官能での総合的な好ましさの差は必ずしも有意にならない** |
| **同一地域の軟水同士（硬度差 数十mg/L以下）** | **極めて弱い／存在しない** | **この条件を扱った査読研究は見つからなかった** |

## 6-3. 個別領域の検証

### ① 水 × だし ― 「官能では有意差なし」

**坂本真里子ほか（2007）「水の硬度が煮出し汁の嗜好性と溶出成分に及ぼす影響」日本調理科学会誌 40(6): 427-434〔査読付き報文〕**〔Evidence Level B〕

- 使用水：南アルプスの天然水（硬度約30 mg/L）／エビアン（291）／コントレックス（約1,551）＝**約50倍の硬度差**
- **かつお節だしの結果（原文）：「官能評価では総合的な好ましさに有意の差は無かった」**
- 野菜スープ・牛肉スープでは有意差あり
- 結論：「好ましさは溶出成分だけでなく、水そのものの味も影響する」

**安達町子（1997）** も同様に、煮干しだしで「5'-IMP・遊離アミノ酸は硬水に多かったが、**官能検査では総合評価に有意の差はなかった**」と報告。

**重要**：「硬水ではCaが昆布のアルギン酸と結合して白濁・えぐみを生む」という説明は料理系ウェブサイトに多いが、**その因果メカニズムを直接検証した査読論文は見つからなかった。**

### ② 水 × 米 ― 通説と逆の結果

**中村武夫ほか（1997）「硬度の異なる調理用水による炊飯米の食味評価に関する研究」日本食品化学学会誌 3(2)**〔B〕

- **結果：香り・味・総合の各項目で、比較的硬度の高い水で炊飯した米飯ほど統計的に有意に高い評価**

**Nakamura & Ohtsubo (2023) *Foods* 12(13): 2510**〔B〕 — 硬水は白未熟粒の食感劣化を抑制。**ただし機器物性測定のみで、ヒト官能パネルは実施されていない。**

> **「軟水で炊いたほうが美味しい」という日本の通説を支持する査読論文は見つからなかった。**
> 一貫しているのは「極端な硬水（300mg/L超）では忌避される」という点のみ。最適域は硬度58.3 mg/L前後という報告がある。

### ③ 水 × 日本酒 ― 鉄・マンガンのみ確立

| 論点 | 証拠の強さ |
| :-- | :-- |
| **鉄・マンガンの悪影響** | **確立（機構解明済み）**。鉄が清酒中のデフェリフェリクリシンと反応しフェリクリシンを生成して着色。酒造用水基準 0.02 ppm以下 |
| K・P・Mg が酵母・麹菌の栄養となる | 生化学的に妥当。**ただし酒質差を定量した査読研究は未確認** |
| 「硬水＝男酒／軟水＝女酒」 | **業界の経験則。査読論文レベルの裏付けは見つからなかった** |

**三浦仙三郎の軟水醸造法**（1887年頃創案、1898年『改醸法実践録』）は、硬度による酒質差を実測に基づき体系化した点で経験則として極めて強固だが、**現代的な統制実験による再現検証は見当たらない。**

### ④ 水 × コーヒー ― この分野が最も足場が固い

**Hendon et al. (2014) *J. Agric. Food Chem.* 62(21): 4947-4950**〔B〕 — 密度汎関数理論により、**Mg²⁺が風味活性化合物の抽出を選択的に増強**することを示した。

**SCA(A) Water for Brewing Specialty Coffee** は定量基準を持つ：TDS 75-250 mg/L（目標150）、カルシウム硬度 17-85 mg/L CaCO₃（目標68）、総アルカリ度40 mg/L前後、pH 6.5-7.5。

> **3分野（だし・米・コーヒー）のうち、コーヒーが最も体系的な研究と定量基準を持つ。**
> **水の差を科学的に語りたいなら、コーヒーが最も安全な足場である。**

## 6-4. 決定的な制約 ― ヒトは水の差を識別できるのか

**Dietrich A.M. & Gallagher D.L. (2013) "Consumer ability to detect the taste of total dissolved solids" *Journal AWWA* 105: E255-E263**〔B〕

> **識別に必要なのは絶対濃度ではなく変化量（ΔTDS）。水どうしをTDSの味で識別するには ΔTDS > 約150 mg/L が必要。**

**日本の軟水は概ね硬度20〜80 mg/L（TDSにして概ね50〜150 mg/L程度）。**

> ### **大野の湧水と、他の日本の名水・水道水との差は ΔTDS 150 mg/L に届かない可能性が高い。**
> ### **すなわち、ブラインドテストで一般消費者が識別できる保証はない。**

これは9/1の現地証言と完全に一致する——地域側「**同じ地下水はなかなか難しい**」「**基本は全部軟水**」。〔E〕

**科学と現地証言が、独立に同じ結論に達している。**

## 6-5. さらに不利な事実 ― 大野の水は「平均値」である

9/2に南部酒造場社長が述べた事実〔E〕：日本百名水選定時のNHK調査で、百名水のうち80数か所を調べて平均値を算出したところ、**大野の水がその平均値とぴたり一致した。**

**「日本の模範的な平均値」であることは、水質の特異性を訴求する方向とは逆に働く。**

## 9-5. Subsidy Trap の検証

提案書Vol2は、県補助（上限6,000万円）と観光庁補助（最大2億円）の活用を前提としている。〔要事実確認〕

**仮にCAPEX 2.4億円（30百万円/室）に対して補助が1億円得られた場合**、実質CAPEXは1.4億円となり、Baseケースの Payback は 6.9年、IRR は約11%に改善する〔F〕。

**しかしこれは事業性の証明ではない。**

| 論点 | 評価 |
| :-- | :-- |
| 補助金は**一度きり**である | 大規模修繕（15〜20年後）には再度の資本が必要。**そのときの補助は保証されない** |
| 補助金には**用途・期間の制約**がある | 目的外使用の禁止、財産処分の制限（一般に10年程度）。**撤退の自由度が下がる** |
| 補助金は**運営費を賄わない** | 稼働35%割れの営業赤字は補助金では埋まらない |
| **本FSの結論** | **本件は Subsidy-dependent である。**この事実を隠したまま「事業」として提示すべきではない |

## 9b-1. 決定的な照合先：DBJ／日本経済研究所（2024年4月）

**「古民家等を活用した分散型エリア開発の現状整理」**は、本件とまったく同じ事業形態を対象とした公的金融機関の調査である。〔Evidence Level A/C〕

### DBJが示す「分散型宿泊施設」の標準モデル

| :-- | --: | --: | --: |
| 一棟あたり客室数 | 87室 | 13室 | **8室** |
| 客室単価（ADR） | 13,000円 | 27,000円 | **35,000円** |
| **客室稼働率** | 76% | 58% | **30%** |
| RevPAR | 9,880円 | 15,660円 | **10,500円** |

# 10. Regulatory / Architecture ― 重大な実装制約

## 10-1. 最大の見落とし：垂直積雪量 3.0m

**福井県建築基準法施行細則に基づく大野市の垂直積雪量は 300cm（旧和泉村は375cm）。**福井県は福井市を除く全域が**多雪区域**に指定され、積雪の単位荷重は積雪量1cmごとに30N/㎡以上。

> **垂直積雪量300cmでの積雪荷重は約9,000N/㎡（≒900kg/㎡）以上。**
> **中心市街地の元町・本町・日吉町・七間・五番・寺町の各エリアはすべてこの区分に含まれる。**

〔Evidence Level A：福井県「建築基準法施行令第86条に基づく垂直積雪量」〕

**提案書Vol1・Vol2には、この数値への言及がない。**これは構造計画と改修コストの**支配的要因**である。

- 屋根の軽量化（瓦→金属）は耐震上の定石だが、**300cm積雪下では別の検討を要する**
- 落雪処理・除雪動線・冬季の営業可否がすべてここに規定される
- Vol2は市に「優先的な除雪動線の確約」を求めているが、**建物側の構造対応コストには触れていない**

## 10-2. 用途変更と建築確認 ― 二重の判定が必要

| 論点 | 内容 |
| :-- | :-- |
| **用途変更の特例** | 令和元年6月施行の改正で、用途変更部分の床面積が**200㎡以下**の特殊建築物（ホテル・旅館を含む）は用途変更時の建築確認手続が不要。改正目的に「古民家の商業的利用」が明記 |
| **ただし** | **確認申請が不要でも、建物は適法な状態にある必要があり、その責任は所有者・運営事業者にある。**法35条（避難・消火）、法27条（耐火）、法35条の2（内装制限）等は適用され続ける。**階段・廊下・排煙・非常照明等の避難施設は、独立部分でない限り用途変更しない部分にも遡及適用** |
| **4号特例縮小（2025年4月1日施行）** | 木造2階建ての町家は**新2号建築物**。**主要構造部の過半の修繕・模様替＝「大規模の修繕・模様替」に該当すると別途建築確認が必要**となり、構造関係規定への適合説明が発生。構造計算が必要な規模が延べ500㎡超→**300㎡超**に引き下げ。法定審査期間 7日→**35日** |

> **すなわち「用途変更が200㎡以下だから確認申請不要」と「工事内容が大規模の修繕だから確認申請必要」は別判定である。**
> 提案書はこの二重判定に触れていない。**工期延伸とコスト増の主要因になる。**

## 10-3. 接道義務 ― 城下町細街路の最大リスク

建築基準法43条1項により、敷地は建築基準法上の道路に**2m以上**接する必要がある。接しない場合は43条2項1号（認定）または2号（許可・建築審査会の同意が必要）による。

**2項1号の認定要件には「利用者が少数」であることが含まれるが、旅館が該当するかは特定行政庁の運用による。**

> **9/1の視察で「密集市街地で工事車両が入りにくい」ことが確認されている。**〔E〕
> **城下町の細街路に面する町家では、接道が実務上の最大リスクになりうる。**
> **物件選定の第一次スクリーニング項目として、接道と43条2項の要否を最優先で確認すべきである。**

## 10-5. 旅館業法 ― 2025年4月の改正を織り込む

2018年改正で「旅館・ホテル営業」に統合され、最低客室数は撤廃済み。

**【2025年4月1日施行の改正】**「旅館業における衛生等管理要領」改正により、玄関帳場代替設備の要件が更新された。

- **上水道普及率 14.33%**（簡易水道を含めても37.27%）。**市民の多くが家庭用ポンプで地下水を直接汲み上げて飲用している**
- **井戸枯れ被害は1970年代に約1,000件、2021年にも48件**
- 昭和53年度から**水田湛水事業**（10月〜翌2月に水田を借上げ湛水）で涵養を実施。令和3年度以降 約40ha

**含意**：「名水を売り物にする事業」が、**市の地下水保全政策と衝突しうる。**サウナ・水風呂・大量の水を使う飲食・クラフト飲料製造は、いずれも揚水量を増やす。**提案書はこの緊張に一切触れていない。**

**設計上の選択肢**：立地を抑制地域外にする、上水・簡易水道を使う、あるいは**「水を使う事業」ではなく「水を守る事業」として設計する**（後者はESG／Natural Capitalの観点で優位）。

## 10-9. 伝統木造の耐震 ― コストと意匠のトレードオフ

長野県「古民家等活用マニュアル」より〔C〕

- 「現在の建築基準法による**仕様規定に基づく簡便な計算方法では、古民家の場合、適合しないことが多い**」
- **許容応力度計算**：一般的だが「耐震壁を設けることが多く、**窓等の開口部が制限される**」
- **限界耐力計算**：「地盤が良ければ補強箇所も少なく費用も少ない。**民家本来の形を保持しやすい**」。反面「構造計算が複雑で、**構造計算費用が高くなる**。調査に時間が掛かる」
- 費用目安：耐震壁 10万円/ヶ所、基礎補強 5万円/m、屋根葺き替え 2万円/㎡
- 「**不特定多数の人が利用する施設に用途を変更するときには、建築基準法や消防法など防火・避難関係の規定が適用されることから、多額な改修費用が必要**」

## Kill Criteria（撤退基準）

「どうなればやるか」ではなく「**どうなればやめるか**」を先に決める。各Gateを通過できない場合、次段への投資を停止する。

### Gate 0（着手判断：0〜3ヶ月）— 投資額 5百万円以内
| 基準 | 撤退条件 |
| :-- | :-- |
| 受入合意 | 対価を伴う体験受入について、**3ヶ月以内に2者以上の書面合意が取れない** → STOP |
| 市の意思 | 物件・制度・データ提供について、**担当課の書面回答が得られない** → STOP |
| 物件 | 使用権原を取得しうる候補物件が**3件未満** → 宿泊事業はDROP（体験のみへPIVOT） |

### Gate 1（PoC判断：3〜12ヶ月）— 投資額 20〜30百万円以内
| 基準 | 撤退条件 |
| :-- | :-- |
| 水質 | 深度別・水源別分析で**有意差が確認できない** → WATER INDEX/CUP/TASTINGをDROP。WATER DRIVENの訴求を「潤沢さ・安価さ・多層利用」へ再定義 |
| 支払意向 | PoCディナーの**実売価格中央値が想定の70%未満**（=17,500円未満） → 高付加価値仮説を下方修正 |
| 集客 | PoC体験の**申込充足率が50%未満** → 需要仮説をDROP |
| 担い手 | PoC運営を**ENOWA社員が全部やらないと回らない**状態 → 事業化はHOLD |

### Gate 2（投資判断：12〜24ヶ月）
| 基準 | 撤退条件 |
| :-- | :-- |
| IRR | 補助金**なし**のBaseケースで**IRR 8%未満** → 民間単独投資はNO-GO |
| Payback | Baseで**12年超** → NO-GO |
| CAPEX | 実施設計時点で**想定の130%超** → 室数を削るか、NO-GO |
| 稼働 | 事前予約・法人契約で**初年度稼働35%相当の見込みが立たない** → NO-GO |
| 人材 | 中核3職種（料理・サービス・支配人）の**内定がゼロ** → 開業延期 |
| 補助 | **補助金ありでしか成立しない**と判明 → Subsidy-dependentと明記し、市と負担・リスク分担を再交渉。ENOWA単独の投資判断としてはNO-GO |

### 恒常的Kill Criteria（開業後）
- 2期連続でEBITDAが赤字 → 事業形態の見直し
- パートナー事業者が2者以上離脱 → コンセプトの再設計

# 30. 最終設問への回答

> **「もしあなた自身が自己資金3億円を投資するInvestment Committeeの責任者だった場合、この案件に投資するか。」**
> **（行政補助金・地域への好意・ENOWAブランドへの期待は一切考慮せず、事業単体として回答すること）**

## 回答：**投資しない。**

### 最大の理由

**補助金を考慮から外した瞬間、この案件は成立しないことが、3つの独立した情報源によって確定しているからである。**

1. **提案書Vol2自身**が「単独投資では回収年数が10年を超え事業化が困難」と明記している
2. **DBJ／日本経済研究所**が「補助金が少なくとも50%程度ない場合は事業としての継続性は難しい」と結論している
3. **本FSの試算**では、DBJ標準の稼働30%／福井県旅館平均27.4%のいずれでも、6室構成でEBITDA赤字となる

**設問が「補助金を考慮せず」と条件づけている以上、答えは一意に決まる。**

### 補足すべき3点

**① 3億円という金額が、この案件には大きすぎる。**
本FSの試算では、6室・改修費3,077万円/室（講の実績）でも総CAPEXは2.45億円。**3億円を投じても6〜8室の宿が1つできるだけであり、分散投資が効かない。**単一物件・単一立地・単一運営者にすべてを賭ける構造は、投資として筋が悪い。

**② ただし、3億円のうち3,000万円なら投資する。**
第14章の90日プラン（130万円）とPhase 1（2,000〜3,000万円）は、**投資判断ではなく情報取得**である。この段階の支出は、
- 損失の上限が明確
- 失敗しても地域に負債を残さない
- **U1（支払意向）・U2（稼働率）・U6（水質差）という、2億円の判断に必要な3変数を直接測定できる**

**期待値の観点では、この3,000万円は3億円より遥かに効率が良い。**

**③ 判断を変える条件（Gate 2の再掲）**

以下が**すべて**満たされれば、投資判断を再検討する。

| 条件 | 閾値 | 現状 |
| :-- | :-- | :-- |
| **室数** | **8室以上**を確保できる物件群 | 提案書は4〜6室 → **不足** |
| **ADR** | 実測WTPの中央値が **45,000円/人以上** | **未測定** |
| **稼働率** | 事前予約・法人契約で**通年50%**の見込み | DBJ標準30%、県旅館平均27.4% → **大幅に不足** |
| **CAPEX** | **2,000万円/室以下**（実施設計ベース） | **未算定**。垂直積雪量300cmの影響が未評価 |
| **運営体制** | 中核3職種の内定 | **未着手** |
| **受入側** | 蔵2者以上の書面合意 | **停止中** |
| **大規模修繕** | 10年目の負担主体が契約で確定 | **未設計** |
| **IRR** | 補助金なしで **8%以上** | 最良ケース（改修1,070万/室・稼働50%）で14.1%、中位（2,000万/室）で7.4% → **CAPEX次第** |

**注目すべきは、8条件のうち6条件が「未測定・未着手」であることである。**
**投資判断の材料がまだ存在しない、というのが最も正確な現状認識である。**

### したがって、投資委員会としての結論

> **「NO」ではなく「NOT YET」。**
> **ただし、現在の提案書のまま（4〜6室・ADR根拠なし・補助金前提・受入側停止中）であれば、明確にNOである。**
>
> **投資すべきは、事業ではなく検証である。**
> **金額：3,000万円。期間：18ヶ月。目的：2億円の判断に必要な3変数の測定。**

# 附録：全面NOで終わらせないために

## 「何を捨てれば成立するのか」

| 捨てるもの | 理由 |
| :-- | :-- |
| **「4〜6室で小さく始める」** | 業界の最低ラインは8室。小規模化はリスクを下げず上げる |
| **「Water dictates everything」** | 科学的裏付けがなく、生産者本人が否定している |
| **「宿泊比率4%からの脱却」** | 指標として成立していない |
| **「ENOWAが投資主体」** | IRRが基準を満たさず、Vol2自身がリスクを市に移転する構成 |
| **Water Summit／海外連携** | 優先度・事業性ともに低い |
| **北陸新幹線を前提とした時間軸** | 開業は2050年代 |

## 「どこまで縮小すれば成立するのか」

**宿泊を持たない「体験＋産品」モデル**なら、投資数百万円〜3,000万円で成立しうる。
ただし本FSの試算では**年間売上上限は約25百万円**であり、**ENOWAの独立事業としては小さすぎる。**
→ **これは事業ではなく、Gate 1の検証装置として位置づけるべきである。**

## 「別の事業モデルなら成立するのか」

**成立可能性が最も高いのは、以下の3つである。**

### 代替案1：**産品の高付加価値化とブランド展開（Export Model）**

**根拠**：河原酢造の98%県外販売という**既に実証された事実**。かつ本人は「営業活動をしたことがない」。〔E〕

- ENOWAの中核能力（食の編集・販路・ブランド）が最も直接的に効く
- **投資が小さく、失敗しても地域に負債が残らない**
- 大野に来なくても価値が伝わる＝**受入キャパシティの制約を受けない**
- 「Destination（来てもらう）」ではなく「**高付加価値な生産地（送り出す）**」

### 代替案2：**運営受託モデル（Management Contract）**

- 市またはSPCが物件を保有・改修し、ENOWAは**運営とブランドのみを受託**
- リスクとリターンの帰属が契約で明確になる
- **Vol2の実質的な内容を、正直に契約形態として表現したもの**

### 代替案3：**既存宿泊施設との連携（Asset-light）**

- 新規改修せず、既存の一棟貸し宿・旅館と提携し、**ENOWAは体験と食のみを提供**
- CAPEXゼロ。9/1で確認された既存の一棟貸し宿は「採算が合わない」状態〔E〕であり、**送客と単価向上は相手にとっても利益になる**
- **Phase 1のテスト販売としても機能する**
