# 01. Executive Verdict

## 判定：**PIVOT**

**事業定義を「ホテル開発を伴う Destination Development」から、「既存資産を用いた有料体験ポートフォリオ ＋ 水循環の科学・保全基盤」へ変更する。**

GOではない。NO-GOでもない。**大型資産投資は HOLD / NO-GO、低CAPEXの有料PoCのみ NOW。**

| 対象 | 判定 | 条件 |

# 02. Why ― 判定の理由（5点）

### 理由1｜市場は縮小している。しかも指標そのものが成立していない

提案書は「年間入込214万人に対し宿泊8.5万人＝宿泊比率4%」という構造的ギャップを出発点とする。**この数字には二重の問題がある。**

**第一に、最新値では市場が縮小している。**

| 指標 | 提案書（R6/2024） | **最新（R7/2025）** | 前年比 |
| :-- | --: | --: | --: |
| 年間観光入込客数 | 2,143,900人 | **1,947,000人** | **90.0%** |
| 宿泊客数 | 84,970人 | **82,000人** | **96.0%** |
| 日帰り客数 | — | **1,865,000人（95.8%）** | 90.0% |
| まちなか観光＋文化施設 | — | 670,300人 | 95.0% |
| **郊外観光地** | — | 1,276,700人 | **88.0%** |

〔A：大野市「令和7年観光入込客数」〕

**第二に、宿泊比率4%は指標として成立していない。**入込客数は「延べ人回」（1人が3施設に立ち寄れば3カウント）、宿泊客数は別単位である。**分子と分母が対応していない比率は転換率として解釈できず、「4%を上げる」という目標設定自体が測定不能である。**〔F〕

> **「214万人の巨大なトップファネルが既にある」という前提は、単位の面でも時系列の面でも成立しない。**
> **なお、令和7年に10%減少した要因は両チームとも未検証であり、最優先の追加調査項目とする。**

### 理由2｜WATER DRIVENの中核仮説が、現地と科学の双方で否定されている

| 仮説 | 現地〔E〕 | 科学〔B〕 |
| :-- | :-- | :-- |
| 水源ごとに味の差がある | 地域側「**同じ地下水はなかなか難しい**」「**基本は全部軟水**」。酢の生産者「**大野の水しか使ったことがないので比較ができない。正直に言うと分からない**」 | **ヒトが水を識別するには ΔTDS > 約150mg/L が必要**（Dietrich & Gallagher 2013）。日本の軟水同士はこれに届かない |
| 水が食の味を決める | 感想中心 | **硬度が50倍異なる水で比較してさえ、かつおだしの官能総合評価に有意差なし**（坂本ら2007・査読報文） |
| 大野の水は特異である | — | 日本百名水選定時の調査で「**百名水の平均値とぴたり一致**」＝標準的〔E〕 |

提案書Vol1は「**Water dictates everything.（水が味のすべてを決める）**」と宣言する。**この主張を、現地の生産者も査読文献も支持していない。**

### 理由3｜供給制約が需要制約より厳しく、しかも現在すでに停止している

提案書は需要側を論じるが、**供給側（誰が受け入れるか）の実数を検証していない。**〔すべて E：9/1・9/2〕

| 事業者 | 受入上限 | 現状 |
| :-- | :-- | :-- |
| 南部酒造場（酒） | 説明20名／回、**宿泊研修は3名×2班＝6名が安全管理上の上限** | **一旦停止中**（「かなりエネルギーがかかる」） |
| 野村醤油（醤油） | — | **停止中**（人手不足＋夏季の熱中症対策） |
| 河原酢造（酢） | — | **4.5人体制**（社員2＋パート1＋社長） |
| ラブリー牧場（酪農） | 10名以上で開催 | 実施中 |

**需要不足ではなく供給側の負荷が理由で停止している。集客に成功するほど、この制約は悪化する。**

### 理由4｜経済性は「規模」で決まるが、提案書の推奨規模は最も不利な水準にある

| 室数 | 想定人員 | 稼働30%（DBJ標準）のEBITDA | 稼働50%のEBITDA |
| :-: | :-: | --: | --: |
| **4室** | 7 FTE | **▲13.2百万円** | +4.5百万円 |
| 6室 | 8 FTE | **▲6.3百万円** | +20.3百万円 |
| **8室** | 9 FTE | **+0.6百万円** | +36.1百万円 |
| 13室 | 13 FTE | +10.1百万円 | +67.7百万円 |

〔F：本FS試算〕

**「8室が最低ライン」に、独立した2つの出所が一致している。**

- **DBJ／日本経済研究所**：標準モデルの前提を**8室**に置く
- **自遊人（講 大津百町の事業者）**：「里山十帖の運営経験から、**8室以上の客室がないと収益が成り立たない**ことが分かっていた」

**提案書Vol2の「初期4〜6室」は、業界が独立に到達した最低ラインを下回る。**
**「小さく始めてリスクを最小化する」は、この業態では逆方向に働く。**

### 理由5｜提案書が最大リスクと認識しているものと、実際の最大リスクが一致していない

提案書Vol2は3つの構造的リスクとして **① 初期CAPEX ② 冬季・気候 ③ 送客分断** を挙げる。

| 順位 | 本FSの評価 | 提案書での扱い |
| :-: | :-- | :-- |
| 1 | **受入側が体験提供を継続できない** | **言及なし** |
| 2 | **稼働率が27〜30%に留まる** | ②として部分的に認識 |
| 3 | **ADR 45,000円が実現しない**（30,000円で営業赤字） | 根拠を示さず前提として使用 |
| 4 | 改修費が想定を超過 | ①として認識 |
| 5 | **運営人材を採用できない** | 市への要望として言及のみ |

> **上位5つのうち3つが提案書で検証されていない。**
> **そしてCAPEXは最大のリスクではない**（後述：真因は稼働率）。
> **リスクの優先順位を誤ったまま、市に対してCAPEX支援を要求している。**

## 7-3. 証拠の強さは「硬度差の大きさ」に依存する

醸造学的に、仕込み水の差が最終製品の官能特性に影響することは知られている。**ただしそれは、灘の宮水（硬度約100mg/L超）と伏見の水（同40mg/L前後）のような明確な差がある場合の話である。**

> **本FSが判定基準として置く水準：水源間の TDS 差が 150mg/L 以上、または硬度差が 50mg/L 以上あれば、官能差の主張が成立しうる。それ未満なら成立しない。**〔F：判定基準の設定。この閾値自体は本FSの設定であり、確立した学術基準ではない〕

**⚠️ 他チーム版に対する反論**：他チーム版は水の硬度に関する具体的数値を挙げ、特定の論文を出典としていた。**当該論文を実際に取得して確認したところ、引用された数値は当該論文に記載されていない。**この数値は採用しない。〔検証済み〕

## 7-4. 決定的な制約 ― ヒトは水の差を識別できるのか

# 10. Financial Model ― 両モデルを最良証拠で組み直す

## 10-1. なぜ「統合モデル」が必要だったか

2つのRed Teamは、独立に財務モデルを構築した。**結論（HOLD／PIVOT）は一致したが、その理由が正反対だった。**

| | 当方版 | 他チーム版 |
| :-- | :-- | :-- |
| 稼働率前提 | **27.4%／30%**（観光庁確定値／DBJ標準）〔A〕 | 45〜48%（出典なし）〔A'〕 |
| CAPEX前提 | **10.7〜40.0百万円/室**（DBJ実勢／講 大津百町実績＋積雪割増）〔A/C〕 | 62.5〜112.5百万円/室（出典なし）〔A'〕 |
| 事業が成立しない理由 | **稼働率が低いから** | **CAPEXが高いから** |

> **他チーム版のCAPEX前提（町家分散 1室あたり1億1,250万円）は、実在する最高値（講 大津百町の3,077万円/室）の3.7倍である。**
> **一方、稼働率前提（45%）は公的統計（27.4%）より17.6ポイント高い。**
> **この2つの誤りは、キャッシュフローに対して逆方向に働き、部分的に相殺していた。**

**したがって「結論が同じだから問題ない」とは言えない。**なぜなら——

> **事業が成立しない理由が「CAPEXが高いから」であれば、Vol2が市に求めるCAPEX支援は解決策になる。**
> **理由が「稼働率が低いから」であれば、CAPEX支援では解決しない。**
> **この違いは、市との交渉の中身を根本から変える。**

**統合モデルは、両者の前提をそれぞれ最良証拠で置き換えたものである。**

# 11. Regulatory / Architecture ― 重大な実装制約

**本章の内容は、提案書Vol1・Vol2のいずれにも記載がない。**

## 11-1. 最大の見落とし：垂直積雪量 3.0m

**福井県建築基準法施行細則に基づく大野市の垂直積雪量は 300cm（旧和泉村は375cm）。**福井県は福井市を除く全域が**多雪区域**に指定され、積雪の単位荷重は積雪量1cmごとに30N/㎡以上。〔A〕

> **垂直積雪量300cmでの積雪荷重は約9,000N/㎡（≒900kg/㎡）以上。**
> **中心市街地の元町・本町・日吉町・七間・五番・寺町の各エリアはすべてこの区分に含まれる。**

**これは構造計画と改修コストの支配的要因である。**

- 屋根の軽量化（瓦→金属）は耐震上の定石だが、**300cm積雪下では別の検討を要する**
- 落雪処理・除雪動線・冬季の営業可否がすべてここに規定される
- Vol2は市に「優先的な除雪動線の確約」を求めているが、**建物側の構造対応コストには触れていない**

**本FSが統合モデルBで「講実績＋積雪割増30%＝40.0百万円/室」というCAPEX水準を置いているのは、この制約による。**〔F〕

## 11-2. 用途変更と建築確認 ― 二重の判定が必要

| 論点 | 内容 |
| :-- | :-- |
| **用途変更の特例** | 令和元年6月施行の改正で、用途変更部分の床面積が**200㎡以下**の特殊建築物（ホテル・旅館を含む）は用途変更時の建築確認手続が不要。改正目的に「古民家の商業的利用」が明記 |
| **ただし** | **確認申請が不要でも、建物は適法な状態にある必要があり、その責任は所有者・運営事業者にある。**法35条（避難・消火）、法27条（耐火）、法35条の2（内装制限）等は適用され続ける。**階段・廊下・排煙・非常照明等の避難施設は、独立部分でない限り用途変更しない部分にも遡及適用** |
| **4号特例縮小（2025年4月1日施行）** | 木造2階建ての町家は**新2号建築物**。**主要構造部の過半の修繕・模様替＝「大規模の修繕・模様替」に該当すると別途建築確認が必要**となり、構造関係規定への適合説明が発生。構造計算が必要な規模が延べ500㎡超→**300㎡超**に引き下げ。法定審査期間 7日→**35日** |

> **「用途変更が200㎡以下だから確認申請不要」と「工事内容が大規模の修繕だから確認申請必要」は別判定である。**
> **提案書はこの二重判定に触れていない。工期延伸とコスト増の主要因になる。**

## 11-3. 接道義務 ― 城下町細街路の最大リスク

建築基準法43条1項により、敷地は建築基準法上の道路に**2m以上**接する必要がある。接しない場合は43条2項1号（認定）または2号（許可・建築審査会の同意が必要）による。**2項1号の認定要件には「利用者が少数」が含まれるが、旅館が該当するかは特定行政庁の運用による。**〔A〕

> **9/1の視察で「密集市街地で工事車両が入りにくい」ことが確認されている。**〔E〕
> **物件選定の第一次スクリーニング項目として、接道と43条2項の要否を最優先で確認すべきである。**

## 11-8. 地下水条例 ― 提案書が触れていない最大の政策的緊張

| 規制 | 内容 |
| :-- | :-- |
| 対象区域 | 施行規則で定める**抑制地域**（市街地中心部） |
| **融雪利用の全面禁止** | 抑制地域内での**融雪目的の地下水使用は禁止**（公益上必要な道路・広場を除く） |
| 採取の届出義務 | ポンプ吐出口の直径**5cm以上**で届出 |
| 水量測定器・月次報告 | 吐出口断面積19.6cm²以上で**測定器を設置し毎月の採取量を市に報告** |

〔A：大野市地下水保全条例〕

> **大野市は「大野市水循環基本計画」において、令和12年度までに地下水揚水量を 8,908千㎥ → 8,017千㎥（1割減）とする定量目標を掲げている。**〔A〕
> **すなわち、大口の新規揚水は市の政策方向と正面から緊張関係にある。**

背景として——上水道普及率**14.33%**（簡易水道を含めても37.27%）、市民の多くが家庭用ポンプで地下水を直接汲み上げて飲用。井戸枯れ被害は1970年代に約1,000件、2021年にも48件。昭和53年度から水田湛水事業（令和3年度以降 約40ha）で涵養を実施。〔A/E〕

**含意**：サウナ・水風呂・大量の水を使う飲食・クラフト飲料製造は、いずれも揚水量を増やす。**提案書はこの緊張に一切触れていない。**

**設計上の選択肢**：立地を抑制地域外にする、上水・簡易水道を使う、あるいは**「水を使う事業」ではなく「水を守る事業」として設計する**（後者はESG／Natural Capitalの観点で優位）。

## 11-9. 伝統木造の耐震 ― コストと意匠のトレードオフ

〔C：長野県「古民家等活用マニュアル」〕

- 費用目安：耐震壁 10万円/ヶ所、基礎補強 5万円/m、屋根葺き替え 2万円/㎡

## 13-3. ENOWAの競争優位の再定義

**由布院のFARM DRIVENを大野に「翻訳」するという発想は正しい。ただし翻訳先が誤っている。**

| | 由布院 | 大野（提案書） | **大野（本FSの提案）** |

# 20. そもそも論 ― 前提そのものを疑う（Q1〜Q5）

### Q1. 大野市は本当に Destination Development を必要としているのか

**判定：必要としているのは Destination Development ではなく、Industry Retention（産業の維持）である可能性が高い。**〔F〕

視察で確認された事実を「深刻度×緊急度」で並べると、観光は最上位ではない。

| 課題 | 深刻度 | 緊急度 | 根拠 |
| :-- | :-: | :-: | :-- |
| **産業の担い手消失** | 極高 | 極高 | 酪農100軒以上→**15軒**／県内に牛乳工場なし。醤油**18社中、麹から一貫は1社**。酒蔵 県内53社→20数社、市内4→3社〔E：9/2〕 |
| **若者流出と職種の欠落** | 極高 | 高 | 進学→就職→結婚で戻らない。製造業と公務員に偏り、事務系・IT・クリエイティブが乏しい〔E：9/1〕 |
| **域内の加工基盤の欠落** | 高 | 高 | 生乳を石川県へ運び製品にして戻す。小ロットの委託加工先がない〔E：9/2〕 |
| **高付加価値品が域内で流通しない** | 高 | 中 | 酢の98%が県外。市内販売は数店舗のみ〔E〕 |
| 観光の滞在時間・宿泊比率 | 中 | 中 | 提案書の主張。ただし指標の定義に疑義 |

**含意**：観光は「解くべき課題」の第一位ではない。ただし**観光は他の課題を解く手段になりうる。**したがって問いは「観光をやるべきか」ではなく、「**観光を、産業維持の手段として設計できるか**」である。**この転換は提案書には存在しない。**

### Q2. 最大の課題は本当に「観光」なのか

**判定：No。最大の課題は「事業者の消滅」である。**

決定的な非対称性がある。**観光施設は後から作れるが、麹から一貫して醤油を作る蔵は、一度失われたら復元できない。**

9/1で確認された酢蔵の事例がこれを実証している——**5代目が戦時中に廃業した時点で地元の商売基盤は完全に消滅し、6代目がUターンして再興したが、地元では二度と売れなかった。**〔E〕**失われた産業は、同じ場所には戻らない。**

現在、大野で同じ危機にあるのは、酪農（15軒）、麹から一貫の醤油（1社）、酒蔵（3社）である。
**5年後に体験の相手がいなくなるリスクは、観光客が来ないリスクより高い。**

### Q3. 観光強化はその課題解決にどの程度寄与するのか

**定量的に見て、寄与は限定的である。**

統合モデルでは、8室・稼働30%の分散型ホテルが生む雇用は約8〜10名。**市の人口は約2.8万人であり、10名の雇用は人口動態を変えない。**〔F〕

ただし、以下の3点では意味のある寄与が期待できる。

1. **職種の多様化**：料理・サービス・企画という、現在市内に乏しい職種が生まれる〔E：9/1で確認された課題に直接対応〕
2. **域内消費の受け皿**：酢の98%県外という構造に対し、**域内で高単価に売れる場**ができる
3. **加工需要の創出**：小ロットの乳製品・加工品に対する安定需要

**含意**：観光の価値は「観光客数」ではなく「**域内経済の循環装置としての機能**」で評価すべきである。**提案書のKPI（宿泊比率・ADR・稼働率）は、この価値を測れない。**

### Q4. ENOWAが入ることが最適なのか

**部分的にYes。ただし「開発事業者」としてではなく「編集者・運営者」としてのみ。**

| 主体 | 大野での適性 |
| :-- | :-- |
| **ENOWA** | **中核能力と課題が一致。**特に「素材はあるが売り方がない」という課題（行政自身が認める〔E〕）に直接対応 |
| DMO | 単価を上げる能力は通常持たない |
| 旅行会社 | 商品がなければ送客先がない |
| ホテル会社 | 8室規模では採算に乗らず参入しない |
| デベロッパー | この規模・立地では投資対象にならない |
| コンサル | 運営を担わないため実装で落ちる |
| 行政単独 | 9/2で行政自身が「ブランディングできていない、価格設定がうまくいかない」と明言〔E〕 |

**結論**：ENOWAの能力は課題に適合している。**ただしハード投資の主体としてENOWAが最適である根拠はない。**Vol2が市に求めている内容は、裏返せば「ENOWAはハードのリスクを取らない」という宣言であり、それならば**ENOWAの役割はソフトに限定すべきである。**

### Q5. 「大野を高付加価値Destinationにする」という前提自体が妥当か

**この前提は現時点では立証されていない。より妥当な前提は「大野を高付加価値な生産地にする」である。**〔F〕

1. **供給制約が需要制約より厳しい。**酒蔵は説明20名／宿泊研修6名が上限で**現在停止中**、醤油蔵も**停止中**、酢蔵は4.5人体制。〔E〕「Destination」は多数の来訪者を前提とするが、**大野の受入能力は構造的に小さい。**
2. **大野の資源は「訪問」より「産品」に向いている可能性がある。**麹から一貫の醤油、静置発酵90日以上の酢、風穴熟成の酒、無農薬米は、いずれも**現地に来なくても価値が伝わる。**実際、酢は98%が県外で売れている。**「来てもらう」より「送り出す」ほうが、既に実証されている。**〔E〕
3. **観光は手段であって目的ではない。**Q3のとおり、観光の意義は域内循環にある。ならば「Destination化」という目的設定は、手段と目的を取り違えている。

> **代替の前提（本FSの提案）**
> **大野を「高付加価値な生産地」として確立し、観光・体験はその生産地を体感させる補助手段として位置づける。**
> **宿泊は、その体験を成立させるために必要最小限の範囲でのみ検討する。**

# 21. 投資委員会への最終回答

> **設問：「もしあなた自身が自己資金3億円を投資するInvestment Committeeの責任者だった場合、この案件に投資するか。」**
> **（行政補助金・地域への好意・ENOWAブランドへの期待は一切考慮せず、事業単体として回答すること）**

## 回答：**3億円は投資しない。1,100万円をコミットし、残りは条件付きで保留する。**

### 21-1. 3億円を投資しない理由

**補助金を考慮から外した瞬間、この案件は成立しないことが、3つの独立した情報源によって確定している。**

| # | 情報源 | 記述 |
| :-: | :-- | :-- |
| 1 | **提案書Vol2自身**〔A'〕 | 「**単独投資では回収年数が10年を超え事業化が困難**」 |
| 2 | **DBJ／日本経済研究所**〔A〕 | 「補助金が少なくとも**50%程度ない場合は事業としての継続性は難しい**」 |
| 3 | **本統合モデル**〔F〕 | 稼働27.4〜30%・CAPEX 30.8〜40.0百万円/室の**あらゆる組み合わせでIRRが負** |

**設問が「補助金を考慮せず」と条件づけている以上、答えは一意に決まる。**

**さらに、金額そのものが案件に対して大きすぎる。**統合モデルでは8室・CAPEX 30.8百万円/室で総額2.46億円。**3億円を投じても8室の宿が1つできるだけであり、分散投資が効かない。**単一物件・単一立地・単一運営者にすべてを賭ける構造は、投資として筋が悪い。

- 損失の上限が明確
- 失敗しても地域に負債を残さない
- **2億円規模の判断に必要な3変数（支払意向・稼働率・水質差）のうち2つを直接測定できる**

**期待値の観点では、この1,100万円は3億円より遥かに効率が良い。**

# 附録A. 全面NOで終わらせないために

## A-1. 何を捨てれば成立するのか

| 捨てるもの | 理由 |
| :-- | :-- |
| **「4〜6室で小さく始める」** | 業界の最低ラインは8室。**小規模化はリスクを下げず、上げる** |
| **「Water dictates everything」** | 科学的裏付けがなく、**生産者本人が否定している**〔E〕 |
| **「宿泊比率4%からの脱却」** | 指標として成立していない |
| **「ENOWAが投資主体」** | 統合モデルでIRRが全ケース負。Vol2自身がリスクを市に移転する構成 |
| **Water Summit** | 前市長構想が継続しなかった事実〔E〕 |
| **北陸新幹線を前提とした時間軸** | 大阪延伸は2050年代 |
| **「スモールコンセッションで初期ハードを公費負担」** | 制度上、民間購入スキームには適用できない |

## A-2. どこまで縮小すれば成立するのか

**宿泊を持たない「体験＋産品」モデル**なら、投資3,300万円で運営できる。
ただし統合モデルの試算では**年間売上27.9百万円・EBITDA 3.4百万円**であり、**共通費・税・本社配賦を乗せるとほぼ消える。**

> **これは事業ではなく、Gate 1 の検証装置として位置づけるべきである。**
> **「体験だけでも十分な事業になる」という評価は、統合モデルでは支持されない。**

## A-3. 別の事業モデルなら成立するのか ― 成立可能性の高い3案

### 代替案1：**産品の高付加価値化とブランド展開（Export Model）** ★最有力

**根拠**：河原酢造の**98%県外販売**という**既に実証された事実**。かつ本人は「営業活動をしたことがない」。〔E〕

- ENOWAの中核能力（食の編集・販路・ブランド）が最も直接的に効く
- **投資が小さく、失敗しても地域に負債が残らない**
- 大野に来なくても価値が伝わる＝**受入キャパシティの制約を受けない**（第20章 Q5 の供給制約を回避）
- 「Destination（来てもらう）」ではなく「**高付加価値な生産地（送り出す）**」
- **Q2 の最大課題（事業者の消滅）に直接効く。**産品が高く売れれば、蔵は続く

### 代替案2：**運営受託モデル（Management Contract）**

- 市またはSPCが物件を保有・改修し、ENOWAは**運営とブランドのみを受託**
- リスクとリターンの帰属が契約で明確になる
- **Vol2の実質的な内容を、正直に契約形態として表現したもの**
- 撤退時のブランド返還条件を必ず明記（NIPPONIA系5施設のブランド離脱事例〔C/D〕）

### 代替案3：**既存宿泊施設との連携（Asset-light）**

- 新規改修せず、既存の一棟貸し宿・旅館と提携し、**ENOWAは体験と食のみを提供**
- **CAPEXゼロ。**9/1で確認された既存の一棟貸し宿は「採算が合わない」状態〔E〕であり、**送客と単価向上は相手にとっても利益になる**
- **Phase 1 のテスト販売としても機能する**（統合モデルAの Stay Package がこれに相当）
