# 0. Executive Summary

9月1日の視察で確認できたことを7点に整理する。

**1｜大野の資源は、単体ではなく相互につながった状態で存在している。**
城下町（空間）・水・米・発酵（酢）・食・暮らしを、それぞれ別の訪問先としてではなく、半日の同一動線のなかで連続して確認できた。資源が「分野別に散在している」のではなく「地理的にも生活的にも近接している」ことが、当日の最大の観察事項である。

**2｜水が、複数の産業と暮らしの共通基盤になっている。**
生活用水、農業用水、工業用水、そして酒・酢という発酵産業の原料水として、同じ地下水が使われている。水が「観光資源としての名水」に留まらず、産業の投入財として機能している点が確認できた。

**3｜城下町に、都市構造そのものが残っている。**
金森長近による町割り、短冊状の街路、七間通り・寺町通り、寺院の配置といった構造が、現在の道路網と生活動線の上にそのまま残っている。文化財の点在ではなく、都市の骨格が残存している状態である。

**4｜建物が、展示物ではなく生活の器として使われてきた／使われている。**
武家屋敷、町家、旧旅館、旧学校、酒屋二階の宴会空間、銭湯。いずれも教育・商売・宴会・入浴といった具体的な生活行為と結びついている。一部では一棟貸し宿、カフェ、ジェラート、コワーキングへの転用がすでに始まっている。

**5｜高付加価値化の余地が、素材側に残っている。**
有機JAS認証、90%精米、静置発酵90日以上、種もみ生産、紙マルチ農法、無農薬栽培。工程の精度は高い一方、「良い素材が低価格で流通している」という認識が地域側から示された。加工・ブランド化の層が薄い。

**6｜一方で、人口流出・雇用・観光の弱さが同時に確認された。**
若者の県外進学とそのままの就職・定着、地域内の職種の偏り（公務員・製造業）、滞在時間の短さ、夜のコンテンツの不足、外国人観光客の少なさ。資源の豊かさと、それを担う人・仕事の細さが並存している。

**7｜資源は「点」として存在し、統合されたストーリーになっていない。**
個々の資源の質は確認できたが、それらを一続きの体験・滞在として編集する枠組みは、現時点では地域側にも視察者側にも存在しない。

> **本レポートの結論の範囲**
> 以上を踏まえ、本レポートは「水が複数資源をつなぐ有力な共通軸ではないか」という水準までを示唆として提示する。構想としての結論づけは行わない。分析・コンセプト開発は次段の別資料に接続する。

# 2. 城下町と都市構造

## 2-1. 確認事項

**FACT** — 当日の説明・現地確認により、以下が確認された。

- 大野の城下町は**金森長近**によって形成された。
- 街路は**京都を参考にした短冊状の構造**をとる。
- **七間通り**、**寺町通り**が主要な軸として現存する。
- 寺町には**16の寺院**が集まっている。
- 寺院の配置には、**城下町の防御**としての機能があったとされる。
- **江戸期から変わっていない道路幅**が残る区画がある。
- 一方で**六間通りは、明治の大火の後に拡幅された**。
- 歴史的建物、町家、旧旅館が市街に**点在**している。

## 2-2. 観察

**OBSERVATION** — 大野の城下町は「保存された文化財が並んでいる」のではなく、**町の骨格そのものが歴史構造として残っている**状態にある。具体的には次の3点で確認できる。

1. **街路が構造として残っている。** 短冊状の町割りと通りの序列（七間・寺町）が、現在の生活道路として機能し続けている。
2. **改変の履歴が読める。** 六間通りの拡幅が「明治の大火後」という時点で説明されることは、町が一度に凍結保存されたのではなく、災害と再建を経て現在の形に至ったことを示す。江戸期の幅員が残る区画との対比が、その履歴を可視化している。
3. **防御という機能が空間配置に残っている。** 16寺院の集中配置が防御目的で説明されることは、宗教施設の集積が信仰上の理由だけでなく都市計画上の意図によることを意味する。

**INSIGHT** — 大野の城下町の価値は、個々の建造物の意匠や年代よりも、**「都市の設計意図が現在の生活空間の上に読み取れる」という点**にある可能性が高い。これは、単体の文化財見学とは異なる体験設計（歩くこと自体が読解になる形式）を許容する条件である。

**NEXT QUESTION**
- 短冊状の町割りは、現在どの範囲まで原形をとどめているか（区画単位での残存度）。
- 16寺院のうち、外部者が立ち入り可能／案内可能なのは何か寺か。運営主体は誰か。
- 江戸期の道路幅が残る区画は、具体的にどこか。図面・地図上で特定できるか。
- 大火（明治）以前・以後の市街図は入手可能か。

## 4-2. 観察

**OBSERVATION** — 当日確認できたのは「水そのものの物性」ではなく、**水が生活・産業・文化にどのように入り込んでいるか**である。具体的には次の3層で確認された。

1. **暮らしの層** — 地下水が日常的に使われ、夏でも冷たいという体感が共有されている。水路が市街の生活動線に含まれている。
2. **産業の層** — 農業用水、工業用水として使われ、さらに酒・酢という発酵産業の原料水になっている。
3. **制度の層** — 水資源を守る政策・条例が存在する。地域として水を管理対象と認識している。

**OBSERVATION** — 「水サミット」構想が過去に存在したという言及は、**水を軸にした地域発信の試みが初めてではない**ことを示す。過去の構想がなぜ継続しなかったのかは、今後の設計上の重要な情報になる。

# 5. 農業・米

## 5-1. 確認事項

**FACT**

- 大野は**米どころ**である。
- **種もみ生産**が行われている。
- **有機栽培**の取り組みがある。
- **紙マルチ農法**が用いられている。
- 醸造事業者による**自社栽培**が行われている（河原酢造：原料米の自社栽培を行う農産部門と、醸造から充填までを担う加工部門の双方で有機JAS認証を取得）。
- **里芋**をはじめとする地域農産物がある。
- **山・盆地・寒暖差**という地形・気候条件がある。

**FACT** — 当日の議論において、**大量生産型農業ではなく、高品質・少量・高付加価値化に余地がある**という論点が提示された。

## 5-2. 観察

**OBSERVATION** — 確認された農業の特徴は、規模ではなく**工程の選択**に現れている。種もみ生産は品質・純度の管理を要する工程であり、紙マルチ農法は除草剤を使わないための手間のかかる選択であり、有機JAS認証は工程の外部検証を伴う。いずれも「効率を優先していない選択」である。

**OBSERVATION** — 醸造事業者が原料米を自社栽培していることは、**農業と加工が同一主体の内部で接続している**事例である。原料段階から製品段階までのトレーサビリティが、事業者単位で成立している。

**INSIGHT** — 山・盆地・寒暖差という条件と、手間のかかる農法の選択が併存していることから、大野の農業は**面積あたりの収量ではなく、単位あたりの質で成立させる方向**に既に部分的に向かっている可能性がある。ただしこれが経営として成立しているかは未確認。

**NEXT QUESTION**
- 種もみ生産の規模、出荷先、大野が担っている位置づけ。
- 有機栽培・紙マルチ農法の作付面積、担い手数、収量と労力の実態。
- 里芋その他の地域農産物の生産量、出荷先、価格帯。
- 寒暖差・積雪が米質に与える影響についての、生産者側の説明と客観データ。
- 高付加価値化を志向する生産者は何名程度いるか。販路をどう確保しているか。

**NEXT QUESTION**

## 6-2. 酢

**FACT** — 視察した酢蔵（工程表上の訪問先は河原酢造）について、以下が確認された。

| 項目 | 内容 |
| :-- | :-- |
| 創業 | 1823年 |
| 原料米 | 有機JAS米 |
| 工程 | 米 → 麹 → 酒 → 酢 |
| 精米歩合 | 90% |
| 志向 | アミノ酸・旨味重視 |
| 発酵方式 | 静置発酵 |
| 発酵期間 | 90日以上 |
| 販売 | 98%が県外 |
| 経営規模 | 小規模 |

**OBSERVATION** — この工程構成には明確な設計思想が読み取れる。

- **90%精米**は、米を削らず残すことを意味する。日本酒が精米によって雑味を除く方向に向かうのに対し、酢では**米の成分をできるだけ残してアミノ酸・旨味に変換する**方向が選択されている。
- **静置発酵90日以上**は、機械的な速醸ではなく時間をかける方式である。回転率を犠牲にした選択である。
- **米→麹→酒→酢**という工程は、酢造りが**酒造りを内包している**ことを意味する。同一の蔵の中に、麹づくりと酒づくりと酢づくりが連続して存在する。
- **有機JAS原料米の自社栽培**と合わせると、**田んぼから瓶詰めまでが一つの主体の内部で連続している**。

**OBSERVATION** — 一方、**98%が県外販売**である。地域内での消費・認知と、実際の市場が乖離している。

# 11. 視察によって見えてきた構造

本章が本レポートの核である。

## 11-1. 資源の連鎖

**OBSERVATION** — 9月1日に確認した資源は、以下の連鎖として整理できる。

```
      山・森林・雪
           ↓
          水
           ↓
        農業・米
           ↓
      酒・酢・醤油
           ↓
      発酵・食文化
           ↓
      城下町・暮らし
           ↓
       観光・体験
```

各層は、以下のFACTによって接続が確認されている。

| 接続 | 確認されたFACT |
| :-- | :-- |
| 山・森林・雪 → 水 | 山・盆地・寒暖差という地形条件。夏でも冷たい地下水。 |
| 水 → 農業・米 | 農業用水としての利用。米どころ。 |
| 農業・米 → 酒・酢・醤油 | 酢蔵の有機JAS原料米自社栽培。酒造りにおける地元の米と水。 |
| 酒・酢・醤油 → 発酵・食文化 | 米→麹→酒→酢の工程。醤油・胡麻豆腐・厚揚げなど水と発酵を要する食。 |
| 発酵・食文化 → 城下町・暮らし | 酒屋二階の宴会文化。料理旅館。朝市。日常の水利用。 |
| 城下町・暮らし → 観光・体験 | 町家・旧旅館・旧学校の一棟貸し宿・カフェ・コワーキングへの転用実例。 |

## 11-2. この構造から読めること

**OBSERVATION** — この連鎖には2つの特徴がある。

1. **各層が地理的に近接している。** 山・水源・田・蔵・町家・宿が、市域内の短い距離に収まっている。半日の動線で複数層を横断できることが、当日実際に確認された。
2. **層をまたぐ主体が実在する。** 酢蔵は「農業・米」層と「酒・酢・醤油」層の両方に属している。分業ではなく統合の事例が既にある。

**INSIGHT** — **大野の価値は、個別資源ではなく、この連鎖にある**と整理できる。

理由は以下である。個々の資源を単体で見た場合、他地域にも同等以上のものが存在しうる。城下町も、名水も、酒蔵も、有機米も、それ自体は大野固有ではない。一方、**「山から水、水から米、米から発酵、発酵から食、食から暮らし、暮らしから空間」という連鎖が、一つの市域内で、しかも徒歩・車での短距離で連続して確認できる**という条件は、単体資源の優劣とは別の希少性をもつ。

**INSIGHT** — 同時に、第8章・第9章で確認したとおり、この連鎖は**現在、地域内でも外部向けにも、一続きのものとして語られていない**。連鎖は実在するが、認識されていない。

# 12. 現時点の示唆

以下は、9月1日時点の**仮説**である。断定ではなく、次段の分析で検証されるべきものとして提示する。

## Insight 1｜大野は「名水の町」だけではない

水は確かに中心にあるが、確認できたのは「水が美味しい」ことではなく、**水が農業・工業・生活・発酵の投入財として複数系統に分岐していること**である。「名水」という語は、この構造の一部しか説明していない。

## Insight 2｜水が、農・発酵・食・産業・暮らしを横断する共通資本になっている

第11章の連鎖において、水はすべての下流層の前提になっている。水は単一の資源ではなく、**複数の産業と生活が共有する基盤（コモン）**として機能している。ただし、水質の実測データによる裏づけは未取得であり、この整理は現時点では観察に基づく。

## Insight 3｜観光資源は既に存在するが、統合的なストーリーになっていない

Nature / Culture / Food / Lifestyle の4分類すべてに具体的な資源が存在する。不足しているのは資源ではなく、**それらを一続きに提示する枠組みと、それを運営する主体**である。

## Insight 4｜大量観光より、高付加価値・少人数・体験型のほうが地域特性に合う可能性がある

根拠は3点。（1）確認された生産主体はいずれも小規模であり、大量の受入は通常生産を圧迫する。（2）価値の所在が工程の精度と背景の物語にあり、これらは少人数でなければ伝達しにくい。（3）宿泊・夜間のコンテンツが未整備であるため、大量集客はむしろ課題を露呈させる。ただし、支払意向と需要規模は未検証である。

## Insight 5｜「作る」のではなく「発見し、編集する」ことが重要

第3章（既存建築の転用実例）、第7章（食文化が既に体系として存在すること）、第8章（Lifestyle資源が観光化されていないこと）、第11章（連鎖が実在するが語られていないこと）は、いずれも同じ方向を指している。**必要なのは新規資源の創出ではなく、既存の日常の再解釈である**可能性が高い。
