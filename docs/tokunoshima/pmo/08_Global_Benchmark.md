# 横断分析 ｜ 14件から見えること

## 1. 成功事例に共通する三条件

| 条件 | 該当事例 |
|---|---|
| **収益と社会成果が、制度として結びついている**（言葉ではなく仕組み） | Aravind、Fogo、Sumba、Chumbe、神山 |
| **教育・研究が「本物」に接続している**（体験の模倣ではない） | Island School、Tetiaroa、UGHE、ARC |
| **地域が主体である**（外から来た人の実験場になっていない） | Fogo、海士町、Chumbe、UGHE |

## 2. 徳之島が持つ、他事例にない強み

| 強み | 他事例との比較 |
|---|---|
| **既に医療組織が存在する** | Sumba は宿が医療を作った。**徳之島は医療が宿を作る** |
| **既に全国研究ネットワークがある** | 40施設の臨床試験センター（→05）。Tetiaroa は一から作った |
| **既に建物がある** | しかも「グループ初の離島病院」という由来つき |
| **既に理念がある** | UGHE の "Global Health Equity" と、「生命だけは平等だ」は同義 |

> **[H] 徳之島は、他の事例が何年もかけて作った要素を、最初から持っている。**
> 足りないのは「それらを一つの場所で結ぶこと」だけかもしれない。

## 3. 最優先で訪問・ヒアリングすべき3件

| 順 | 事例 | 目的 |
|---|---|---|
| 1 | **隠岐島前高校／海士町** | 国内・離島・教育・座組み。最も再現性が高い |
| 2 | **UGHE（ルワンダ）** | 理念・立地・奨学金・隣接病院。構造が最も近い |
| 3 | **Fogo Island Inn** | 収益還元を制度化する方法 |

**[V] 訪問可否・時期・費用を検討する。少なくとも1は初期に必須。**
