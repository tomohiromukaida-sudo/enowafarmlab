## 1. 情報の分類ルール（本PMOの全文書で厳守）

| タグ | 意味 | 扱い |
|---|---|---|
| **[F]** | FACT。一次資料または信頼性の高い公開情報で確認済み | 出典を必ず併記。対外資料で使用可 |
| **[U]** | USER PROVIDED INFO。関係者・チームから提供された未検証情報 | 対外資料で断定しない。面談で確認 |
| **[H]** | HYPOTHESIS。現時点の仮説 | 「正解」として扱わない |
| **[P]** | PROPOSAL。我々からの提案 | 相手の意向確認前に売り込まない |
| **[V]** | TO VERIFY。要検証・要調査 | 誰が・いつまでに、を明記 |

**本構想全体が、現時点では向田・町田チームによる [H] である。**
徳洲会理事長・事務局・旧病院PJ責任者の正式意向ではない。

## 5. PMOの進め方（この順を守る）

```
IDEA → RESEARCH → FACT CHECK → HYPOTHESIS
    → BUSINESS MODEL → FEASIBILITY
    → STAKEHOLDER INTERVIEW → CONCEPT REFINEMENT
```

**最初のゴールは完成企画書ではない。**
「これは徳洲会・徳之島にとって、本当に30億円を投じる価値のある次の40年のプロジェクトになり得るか」を検証すること。

**このアイデアに惚れ込んで「正解」として企画書を作らない。**
