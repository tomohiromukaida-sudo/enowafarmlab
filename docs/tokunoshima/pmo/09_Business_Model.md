# 09 ｜ Business Model

**宿泊＋教育＋研究＋企業＋一般観光の Mixed Demand Model**

[H] 構造の提案。数値は 10 で扱う。

---

## 1. 前提 ｜ 通常のホテル指標だけで評価しない。ただし採算性は必ず検証する

ADR / RevPAR / Occupancy だけで評価しない。しかし、**ホテル事業としての採算性は必ず成立させる。**
「社会的意義があるから赤字でよい」は、この事業を殺す。理由は二つある。

1. 赤字施設は、経営が苦しくなった瞬間に**最初に閉じられる**
2. **クロスサブシディ（→04）は、黒字がなければ成立しない。** 奨学枠を支えるのは一般宿泊の利益である

> **[H] 収益性は、理念の敵ではない。理念の前提条件である。**

---

## 2. 需要の複線化（Mixed Demand Model）

| | セグメント | 特性 | 季節性 | 曜日 | 価格 |
|---|---|---|---|---|---|
| **A** | 徳洲会内部需要（応援医師・看護師・研修・会議・長期滞在） | 予測可能。ベース | 通年 | 平日 | 内部料金 [V] |
| **B** | Education（子ども・高校生・大学生・医学生・海外学生） | 期間集中。大人数 | 長期休暇 | 通年 | 奨学枠あり |
| **C** | Research / Innovation（研究者・企業・スタートアップ・大学） | 長期滞在。高単価許容 | 通年 | 平日 | 中〜高 |
| **D** | General Hospitality（一般旅行者、高付加価値、Wellness、Longevity Stay） | 収益の主力 | 繁忙期偏重 | 週末 | 高 |
| **E** | Corporate（企業研修、Leadership、Executive Retreat、Innovation Camp） | 貸切。高単価 | 通年 | 平日 | 最高 |
| **F** | Events（国際会議、シンポジウム、Summit） | 年数回。全館 | 指定 | 指定 | 最高 |

### この組み合わせが効く理由

```
        繁忙期・週末        閑散期・平日
      ┌──────────────┬──────────────┐
      │  D 一般旅行者   │  A 内部需要    │
      │  B 教育（休暇） │  C 研究滞在    │
      │                │  E 企業研修    │
      └──────────────┴──────────────┘
              ↑ 高単価          ↑ 安定稼働
```

**一般ホテルの最大の弱点は、閑散期と平日である。**
A・C・E がそこを埋める。**これは観光需要だけでは絶対に作れない構造であり、徳洲会だからこそ持てる。**

## 3. 収益構造

| 収益源 | 区分 | 備考 |
|---|---|---|
| 客室 | 事業 | 全室同一料金・内外同一料金の検討（→ 5節） |
| F&B | 事業 | 島の食。GATHER 層の飲食を含む |
| 研修・プログラム | 事業 | B・E。**単価が高く、季節性がない** |
| 研究滞在・フィールド利用 | 事業 | C。施設利用料＋滞在費 |
| 貸切・イベント | 事業 | E・F |
| 物販 | 事業 | 島の産品 |
| スポンサー | 非事業 | 企業CSR/CSV |
| 寄付・基金運用益 | 非事業 | **奨学枠の財源（→04）** |
| 助成・補助金 | 非事業 | 財団助成、公的補助 |
| ふるさと納税 | 非事業 | 3町との連携 |

**[H] 事業収益で施設を回し、非事業収益で「平等」を実装する。二階建てにする。**

## 4. STAY / GATHER の二層と収益の関係

（既存資料 `../20_who-is-this-for.md` の構造を継承）

| 層 | 役割 | 収益 |
|---|---|---|
| **STAY**（客室） | 事業を成立させる。数を絞り単価を守る | 直接収益の主 |
| **GATHER**（旧病院の大空間） | 混ざる。教育と研究が起きる | 直接収益は小。**しかし STAY の単価を支える** |

> **GATHER に「ここでしか会えない人」がいるから、STAY が高くても選ばれる。**
> 14歳の子どもが朝食で Longevity 研究者と出会う ── **この偶発性こそが商品である。**

**[V] GATHER の運営主体と費用負担を誰が持つか。** ホテル事業に全部乗せると収支が苦しくなる。財団分離を検討（→ 6節）。

## 5. 価格思想と、その代償（[P]／要検証）

既存資料 `../22_tokuda-doctrine.md`・`../24_tokuda-episodes.md` から。

| 施策 | 徳田流の根拠 | 事業上の代償 |
|---|---|---|
| 全室同一料金 | 差額ベッド代を取らない | 客室仕様の均質化が必要。上位単価を取れない |
| 繁忙期も同一料金 | 同上 | **繁忙期の収益機会を捨てる。影響が最も大きい** |
| 内外同一料金 | 生命だけは平等だ | 二重価格による収益機会を捨てる |
| 前金・デポジットなし | 入院保証金不要 | 無断キャンセルリスク |
| チップを受け取らない | 贈り物を受け取らない | ほぼ影響なし |
| 長期逓減価格 | 離島に人を送り続けた思想 | 平均単価が下がる。**ただし稼働は安定する** |
| 24時間チェックイン／アウト | 年中無休・24時間 | 清掃・人員コスト増 |
| 24時間・無料送迎 | 赤信号でも迎えに行け | 車両・人員コスト |

### [V] 最重要の未解決論点

**内部料金（A）を設けることは、「全室同一料金・内外同一料金」と矛盾しないか。**

- 矛盾する、と整理するなら → 内部にも同一料金。ただし内部需要の獲得力は落ちる
- 矛盾しない、と整理するなら → 「所属による差」は認めることになり、思想が緩む
- **第三案：内部需要は「宿泊」ではなく「研修・業務」として別建てにする**

**この整理をせずに価格表を作らない。ここは思想の一貫性が最も試される箇所である。**

## 6. 運営主体の構造（[P] 案）

| 主体 | 担うもの | 理由 |
|---|---|---|
| **事業会社**（またはホテル運営受託） | 宿泊・F&B・企業研修・イベント | 収益責任を明確にする |
| **財団／一般財団法人** | 奨学金、教育プログラム、研究支援、Alumni | **寄付・助成を受けるには非営利主体が要る** |
| **徳洲会** | 建物・理念・医療連携・内部需要 | オーナー |
| **町田×向田＋RATA** | ブランド・体験設計・プログラム開発（→13） | 上流の編集 |

> **[H] 事業会社の利益の一定割合を財団に拠出する規程を、最初に作る。**
> Fogo Island / Shorefast の「余剰の全額を地域に再投資」を制度として固定した形（→08 A-2）。
> **後から作ると、必ず作られない。**

## 7. 成果指標

| 区分 | 指標 |
|---|---|
| 事業 | GOP、GOP率、稼働率、ADR、RevPAR、セグメント別売上構成 |
| 安定 | 閑散期稼働率、平日稼働率、**内部需要由来稼働率**（→07） |
| 平等 | 奨学枠人数と比率、島民利用数、島の子の参加率 |
| 教育 | プログラム参加者数、Alumni 登録数、**進路が変わった人の数** |
| 研究 | 滞在研究者数、共同研究件数、論文・成果数、企業実証件数 |
| 地域 | 島内雇用数、島内調達比率、3町への経済効果 |

**[V] 「進路が変わった人の数」は、初年度から追跡設計を組み込まないと取れない（→04）。**

## 8. この事業の成否を分ける3つの問い

1. **内部需要（A）が、閑散期・平日をどれだけ埋めるか** → 07
2. **教育・研究（B・C・E）が、本当に費用を払うか** → 06、10
3. **一般旅行者（D）が、この場所を「泊まりたい」と思うか** → ブランドの問題。ここは町田・向田の領域

**3が成立しなければ、1と2があっても事業にならない。**
逆に3だけでは、徳洲会がやる意味がない。**三つ全部が要る。**
