# 16 ｜ 事務局長（次期ホテル総支配人）面談ガイド

**これが、次の実アクションである。** 理事長面談（→ 11）は、この後に置く。

---

## 1. 相手の性格を理解する

| | 内容 |
|---|---|
| 現職 | 徳之島徳洲会病院 事務局長 [U] |
| 見込み | **今後、ホテルの総支配人になる予定** [U]／[V] 確度を確認 |
| 導線 | 向田の親戚である町議会議員の、その弟（徳洲会病院勤務、向田とほぼ同年齢）からの紹介 [U] |
| [V] | **紹介者と事務局長が同一人物か、別人か。先に確定させる**（→ 17 冒頭） |

### 理事長との違い ── 話し方を変える

| | 理事長 | **事務局長／次期総支配人** |
|---|---|---|
| 関心 | なぜ残すのか。理念。次の40年 | **どう回すのか。自分が背負うことになる現実** |
| 持っている情報 | 意思と方向 | **投資条件、設計進捗、内部データ、島の実情** |
| 我々への警戒 | 外部のコンサルが売り込みに来た | **自分の仕事に口を出しに来た** |
| 効く話 | 大きな問い | **具体的な役に立つこと** |

> **[!] 最大の注意：この人は、これから「運営する側」になる。**
> 壮大な構想を語るほど、「では誰がそれを回すのか」という不安を与える。
> **構想ではなく、この人の仕事が楽になる話から入る。**

---

## 2. この面談の目的（順序）

1. **関係をつくる**（今後、最も長く一緒に働く相手になる可能性が高い）
2. **現実を教えてもらう**（投資条件・設計・内部需要・島の実情。PMO 07・10 の空白）
3. **理事長の考えを、この人の理解を通して知る**
4. 我々が何をできるかを、**押し付けずに**伝える
5. **理事長面談への導線をつくる**

**構想（Global Life Lab、キッザニア医療版、キューバモデル）は、この面談では出さない。**
向こうから「どんな構想か」と聞かれたら、**問いの形**で返す（→ 6節）。

---

## 3. 時間配分（90分想定）

| 時間 | 内容 |
|---|---|
| 0–10分 | 挨拶。紹介者への感謝。**「まず現場のことを教えていただきに来た」と明言** |
| 10–20分 | 我々が何をしてきたチームか（ENOWA YUFUIN。**短く**） |
| 20–70分 | **ヒアリング（下記4節）** |
| 70–80分 | 我々にできそうなこと（求められた範囲で） |
| 80–90分 | 次のステップ。現地視察と理事長面談の相談 |

**提案は合計20分以内。** 残り70分は聞く。

---

## 4. ヒアリング項目

### A. 事実確認（PMO の空白が最も埋まるところ）

**建物**
- [ ] 旧病院の図面・構造図・設備図は残っているか。見せてもらえるか
- [ ] 階数、延床面積、病床配置
- [ ] 耐震診断の有無と結果（1986年築＝新耐震以降だが実測は別）
- [ ] アスベスト等の調査状況
- [ ] 設備（電気・給排水・空調・エレベーター）の状態
- [ ] 自家発電・受水槽の能力（災害時の受入力に直結）
- [ ] **バリアフリー性能**（廊下幅、エレベーター、トイレ、段差）
- [ ] 台風・塩害への対応状況
- [ ] 移転後、いま建物はどうなっているか（閉鎖／一部使用／管理者）

**事業条件**
- [ ] 投資規模（30億円は確定か、目安か、上限か）
- [ ] **その投資に、回収を求めているのか**（← 最重要。→ 17 の4節）
- [ ] 客室数・カテゴリーの想定
- [ ] 開業想定時期
- [ ] **設計はどこまで進んでいるか。設計者は決まっているか**
- [ ] オペレーターの検討状況
- [ ] 補助金・自治体との関係
- [ ] 意思決定のプロセス（誰が、いつ、何を決めるのか）

**内部需要（PMO 07 のデータ依頼を、ここで直接渡す）**
- [ ] 応援医師・看護師の年間派遣人数と延べ日数
- [ ] 研修医・医学生・実習生の年間受入人数
- [ ] **それらの人は、いま島のどこに泊まっているか**
- [ ] その宿泊費の水準と負担者
- [ ] **繁忙期に、島で宿が取れなくて困ることはあるか**
- [ ] グループの研修・会議で、徳之島開催が可能なものはあるか
- [ ] 島外からの受診者・付添者の宿泊需要

### B. 意向と背景

- [ ] **なぜ壊さずに残すことになったのか**（この人の理解している経緯）
- [ ] **なぜホテルなのか**。他の用途は検討されたか
- [ ] 理事長は、この件に何を期待しておられるとお感じか
- [ ] 徳田虎雄氏のレガシーとの関係を、どう受け止めているか
- [ ] **この病院で、これまで何人が生まれたか**（記録は残っているか）
- [ ] 島民は、この建物をどう思っているか
- [ ] 3町（徳之島町・伊仙町・天城町）との関係

### C. この人自身のこと（最も大事かもしれない）

- [ ] **総支配人になられると聞きました。どうお感じですか**
- [ ] ホテル運営のご経験は
- [ ] **いま、いちばん不安なことは何ですか**
- [ ] どんな施設にしたいと思っておられますか
- [ ] 何があれば助かりますか

> **この4問が、この面談で最も価値がある。**
> 相手の不安を聞き出せれば、我々の役割は「売り込む」から「支える」に変わる。

### D. 新構想に関わる確認（押し込まずに、反応を見る）

- [ ] 教育・研修機能を持たせる構想はあるか
- [ ] 島の子どもたちに使ってほしいという話は出ているか
- [ ] **新病院でメディカルツーリズムを目指すという話があったと聞きましたが、いまどうなっていますか。ハードルは何ですか** [U] 向田情報
- [ ] 海外からの医療者・研修生の受入について、話は出ているか
- [ ] 徳洲会の看護学校・奨学金・就学支援の制度

## 6. 「どんな構想をお持ちですか」と聞かれたら

売り込まない。**問いで返す。**

> 「まだ決めていません。ただ、ひとつだけ気になっていることがあります。
> この建物は、徳洲会グループで**初めての離島病院**だったと知りました。
> 40年間、島の医療を担った建物です。
>
> **これを残すということは、何を残すということなんだろうか**と、ずっと考えていまして。
> そこを、今日うかがいに来ました。」

これ以上は言わない。相手が話し始めたら、聞く。

---

## 7. やってはいけないこと

- **構想を語らない。** 特に Global Life Lab、キッザニア医療版、キューバモデルは出さない
- **「ラグジュアリーホテルではない」と我々から言わない。** 相手の想定を先に潰すことになる
- 理事長の意向を、我々が代弁しない
- 徳田虎雄氏の人物評価を語らない
- **運営の難しさを指摘しない。** これから背負う人に、不安を足さない
- 費用・契約の話をこちらから出さない
- 紹介者（親戚筋）の立場を悪くしない。**この面談が失敗しても、紹介者が困らないようにする**

## 9. この面談の成功条件

**構想が受け入れられることではない。**

| ✅ 成功 | ❌ 失敗 |
|---|---|
| この人が「また話したい」と思う | 感心されたが、次がない |
| 建物データと内部需要データが手に入る | 我々が話して終わる |
| **投資の性格（回収を求めるか）がわかる** | 構想を気に入られたが、条件を聞き忘れる |
| この人の不安を一つ聞けた | |
| 理事長面談への道筋が見えた | |
