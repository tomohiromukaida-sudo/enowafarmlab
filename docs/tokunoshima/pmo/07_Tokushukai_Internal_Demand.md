# 07 ｜ 徳洲会グループ内部需要

## ⚠ 本書の前提 ｜ 現時点で推計値を出さない

内部需要は本事業の**収益の土台**であり、同時に**最も外部から見えない数値**である。
公開情報から推計すれば、それは検証ではなく創作になる。

したがって本書は**数字を出さない。** 代わりに、

1. 必要なデータ項目を特定する
2. 算定ロジックを確定する
3. データが入った瞬間に数字が出る状態にする

ここまでを納品物とする。**[V] データ入手後、24時間で数値化できる。**

---

## 1. なぜ内部需要が決定的なのか

一般ホテルは開業初日にゼロから集客する。**徳洲会には、開業前から存在する需要がある可能性がある。**

| 内部需要が持つ意味 | 効果 |
|---|---|
| ベース稼働 | 需要変動の下支え。閑散期の底が上がる |
| 平日稼働 | 観光需要は週末偏重。研修・応援は平日 |
| 事業計画の説得力 | 金融機関・理事会に対する最も強い根拠 |
| 立ち上がりリスクの低減 | 開業初年度の赤字幅を圧縮 |
| **Living Lab の起点** | 医療者が日常的に滞在する場に、研究と教育が乗る |

> **[H] 内部需要が年間 X 泊あるかどうかで、この事業の性格が変わる。**
> 多ければ「内部需要を土台に外部へ開く施設」、少なければ「純粋な市場勝負のホテル」。**設計も価格も変わる。**

## 3. 算定ロジック（データ投入で即算出）

### 内部需要の年間延べ宿泊数

```
内部延べ宿泊数（泊/年）
 = Σ [ 区分ごとの 年間人数 × 平均滞在日数 × 当施設利用率 ]

  区分 = 応援医師／応援看護師・コメディカル／事務・管理／
        研修医・医学生／実習生／研修・会議参加者／
        研究関係者／受診者・付添

  当施設利用率 = 実際に当施設を選ぶ割合（0〜1）
    ※ 既存宿泊先からの転換率。ここは仮定値になるため感度分析の対象
```

### 内部需要による稼働寄与

```
内部由来稼働率 = 内部延べ宿泊数 ÷ ( 客室数 × 365 × 平均在室人数 )
```

### 内部需要売上

```
内部売上 = 内部延べ宿泊数 × 内部料金単価
  ※ 内部料金は一般料金より低く設定される想定。
     ただし「全室同一料金／内外同一料金」の思想（→ 09）との整合を要検討。
     [V] 内部料金を設けることが思想に反しないかの整理が必要。
```

### 感度分析の軸

| 軸 | 範囲 |
|---|---|
| 当施設利用率 | 30% / 50% / 70% / 90% |
| 内部料金単価 | 現行出張規程上限 × 0.8 / 1.0 / 1.2 |
| 客室数 | 50 / 80 / 100 / 150 |

**→ この3軸で、内部需要だけで何%の稼働が埋まるかを出す。→ 10 に接続。**

## 4. 判断基準（[P] 事前に決めておく）

データが出た後で基準を決めると、都合よく解釈してしまう。**先に決める。**

| 内部由来稼働率 | 判断 |
|---|---|
| **30%以上** | 内部需要を土台にした設計が可能。事業計画の説得力が大きく上がる |
| **15〜30%** | 補助的。閑散期対策として有効だが、外部需要が主軸 |
| **15%未満** | 内部需要は前提にしない。純粋な市場勝負として設計する |

---

## 5. 注意 ｜ 内部需要に頼りすぎない

1. **内部需要は「意思決定で消える」。** 方針が変われば一夜でゼロになる。これを事業の生命線にしない
2. **既存の宿泊先を奪うだけなら、島にとって新規価値はない。** A-6 を必ず確認する
3. **内部利用が多すぎると、外部から見て「グループの保養所」に見える。** 国際拠点というブランドと矛盾する。**上限を設けるべきかも検討する**
4. **内部料金を作ることは、「全室同一料金・内外同一料金」の思想と衝突しうる。** [V] 整理が必要（→ 09、14）
