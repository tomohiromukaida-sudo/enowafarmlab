# 13 ｜ 町田×向田＋RATA の参画スキーム

---

## 1. 大原則

**本件をRATA単独案件として整理しない。**

中心は、

> **町田 × 向田 ／ Hospitality Brand & Destination Development Team**

RATAは、そこに専門性を付加する立場である。

対外的な説明順序も、この順を崩さない（→ `../00_project-premise.md`）。

---

## 2. 役割分担

### 町田・向田チーム（中核）

| 領域 | 内容 |
|---|---|
| **ブランド戦略** | なぜこの場所か、を定義する。すべての判断基準となる一行 |
| **コンセプト開発** | 事業の骨格。何を作り、何を作らないか |
| **顧客体験** | 滞在の時間軸に沿った体験設計 |
| **ホスピタリティ設計** | サービス思想、オペレーター選定支援、スタッフ育成の起点 |
| **事業全体の編集** | 建築・食・運営・PRを一つの思想で統合する。**分断させない役割** |
| **ブランドストーリー** | 語られる形をつくる |
| **国内外への発信** | メディア、アワード、国際発信 |

**根拠：** ENOWA YUFUIN で、一つの宿泊施設を「その土地を訪れる目的となるブランド」に変えた経験（→ `../01_enowa-methodology.md`）。

### RATA（付加）

| 領域 | 内容 |
|---|---|
| **Regenerative Strategy** | 環境再生と観光・事業を同じ設計に置く方法論 |
| **Art Masterplan** | アートの役割定義と全体計画。**アートホテルにしない設計** |
| **Artist Curation** | 国内外アーティストの選定・滞在制作 |
| **Ocean / Nature Program** | 海・自然のプログラム設計 |
| **Ocean Gaia 連携** | 既存プロジェクトとの接続 |
| **環境教育** | 子ども・学生向けの環境プログラム |
| **地域連携** | 徳之島の既存ネットワーク。3町・事業者・住民 |
| **International Network** | 海外のアーティスト・研究者・実践者 |
| **Regenerative Experience** | 訪れることが再生になる体験設計 |
| **Program Development** | 教育・研究プログラムの開発運営（→ 04） |

## 3. RATAアセットの扱い方（順序を間違えない）

**❌ やってはいけない順序**

```
RATAにOcean Gaiaがある → だから海洋プログラムを入れよう
```

**⭕ 正しい順序**

```
徳田思想・徳洲会・徳之島という上位目的がある
  → そのために何が必要か
    → その必要に対して、RATAは何を提供できるか
```

**RATAの既存事業を主役にしない。** 上位目的に対して有効な場合にのみ、接続する。

---

## 4. アートの役割（限定的に定義する）

**アートホテルにしない。** アートは目的ではなく、以下の機能を担う手段である。

| 機能 | 内容 |
|---|---|
| 病院の記憶を翻訳する | 恐怖や重さを、別のものに変換する |
| 生命について考えさせる | 医療や科学では扱いにくい問いを可視化する |
| 自然との関係を再構築する | |
| 異なる文化・言語の人をつなぐ | 言葉を介さない共通言語 |
| 世界への発信力をつくる | |

検討しうる形式：Artist in Residence／Bio Art／Environmental Art／Science × Art／Ocean Art／Public Art。

**[V] どれを採るかは、ブランドの方向が定まってから。現段階では決めない。**

---

## 5. 我々が担わない領域（明確にしておく）

| 領域 | 誰が担うか |
|---|---|
| 建築設計・構造・設備 | 建築家・設計事務所（選定基準は `../21_design-doctrine.md`） |
| 施工 | ゼネコン・地元施工者 |
| ホテル運営実務 | オペレーター、または自社運営組織 |
| 医療・研究の実務 | 徳洲会（臨床試験部会・研究部門）、大学、企業 |
| 法務・税務・会計 | 専門家 |
| 資金調達 | 徳洲会・金融機関・財団 |

> **我々は「思想を通す役割」であって、すべてを実行する主体ではない。**
> ただし、**選定と統合の責任は持つ。**

## 7. なぜこのチームなのか（面談で聞かれたときの答え）

1. **上流から入れる。** 設計が固まる前にブランドを立てられる稀なタイミング
2. **土地の固有性をブランドに変えた経験がある。** 徳之島は、翻訳すべき固有性が桁違いに強い
3. **事業主体がホテル事業者でないこと。** だからこそ、通常のホテル開発の定石に縛られず、理念から立ち上げられる。**既存のホテルチェーンには構造的に不可能**
4. **島に既にネットワークがある。** RATAが徳之島で活動している

**※ ただし、これを最初から並べない。** 求められたときに答える。
