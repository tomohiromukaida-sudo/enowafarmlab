# 05 ｜ Longevity / Healthcare Innovation との接続可能性

[H] 仮説と [V] 検証課題。**「徳之島＝長寿の島」というイメージだけで研究価値を断定しない。**

## 1. まず、前提を疑う

### [F] 確認できていること

| 項目 | 内容 | 出典 |
|---|---|---|
| 伊仙町の合計特殊出生率 | 2003–07年 2.42（全国1位）、2008–12年 2.81（全国最上位）、2013–17年 2.46 | 松下政経塾、北海道新聞、全国町村会 |
| 百寿率 | 人口1万人あたり100歳以上人数が高い | 全国町村会 |
| 長寿者の輩出 | 泉重千代、本郷かまと | 全国町村会 ほか |

### [V] 確認できていないこと ── ここを埋めずに構想を進めない

- **平均寿命・健康寿命の実数**（徳之島3町別、全国・鹿児島県との比較、経年変化）
- **疾病構造**（生活習慣病、透析導入率、循環器・脳血管、がん罹患）
- **医療アクセス**（受療行動、島外搬送数、専門医充足）
- **生活習慣**（食、身体活動、飲酒、喫煙、睡眠、社会的つながり）
- **人口動態**（転出入、若年層の島外流出、将来推計）
- **出生率が高い要因**（[F] 九州大学の研究等が育児ネットワーク仮説を扱っている。要精読）

**[V] 特に重要：出生率の高さと長寿は別の現象である。** 両方あることを「生命の島」と表現するのは物語としては強いが、**科学的因果として語ってはならない。**

### [F] 「長寿の島」を安易に使うことのリスク

**Blue Zones（沖縄・サルデーニャ・イカリア・ニコヤ・ロマリンダ）** は Dan Buettner らが2004年に提唱し、National Geographic と米国立老化研究所の支援で調査された概念である。近年、**年齢記録の妥当性や方法論に対する批判**が提起され、研究者側が The Gerontologist（2025）等で反論している状況にある。
（出典：Science.org、The Gerontologist / Oxford Academic、bluezones.com、National Geographic）

> **教訓：長寿地域のブランド化は、学術的批判にさらされる。**
> 徳之島で同じことをするなら、**最初からデータの取り方と検証可能性を設計に組み込む。**
> 逆に言えば、そこを厳密にやれば「批判に耐える長寿研究フィールド」という稀有なポジションが取れる。

**[V] 泉重千代氏の年齢記録には学術的に異論がある。対外資料で「世界一の長寿記録」と断定しない。**

## 2. 徳之島が持つ研究フィールドとしての条件

| 条件 | 内容 | 研究上の意味 |
|---|---|---|
| 人口規模が把握可能 | 3町、島全体で数万人規模 | 悉皆に近い調査が可能 |
| 地理的に閉じている | 離島 | 交絡が少ない。移動の追跡がしやすい |
| 医療機関が特定できる | 徳之島徳洲会病院ほか | 診療データの集約可能性 |
| 出生率が全国最高水準 | [F] | **出生・小児コホートが組める希少地** |
| 高齢化と長寿が併存 | [V] 実数確認 | Longevity 研究 |
| 食・農・海が同一圏内 | サトウキビ、黒糖、島の野菜・魚 | 食×健康の一体観測 |
| 世界自然遺産 | [F] 2021年登録 | Planetary Health / One Health の文脈 |

> **[H] 徳之島の最大の研究価値は「長寿」ではなく、
> 「生まれてから死ぬまでを、一つの島で通して観測できること」かもしれない。**
>
> 出生率日本一と高齢長寿が同じ島にあるのは、**ライフコース研究のフィールドとして極めて稀**である。

**[V] この仮説の妥当性を、疫学・公衆衛生の専門家に検証してもらう。**

## 4. [F] 最重要の構造的発見 ── 徳洲会は既に基盤を持っている

| 資産 | 内容 |
|---|---|
| 臨床試験部会 | グループ各病院の治験を束ねる「司令塔」 |
| 40施設の臨床試験センター | 全国規模の実施体制 |
| 各種倫理審査委員会 | 弁護士・臨床薬理学者・生物統計学者・生命倫理学者 |
| 医療情報データベース研究 | 情報公開を実施 |
| 方針 | 先端医療の推進、真の医薬品開発、**治験の空洞化の打開**、ゲノム薬理 |

（出典：徳洲会 臨床試験部会、徳洲会グループ臨床研究）

> **[H] 「治験の空洞化の打開」という既存方針と、
> 「離島に分散型臨床試験のフィールドを持つ」ことは、直接つながる。**
>
> 徳之島 Living Lab は、新規事業ではなく **既存戦略の延長として提案できる可能性がある。**

**[V] 臨床試験部会・研究部門に、この構想への関心があるかを確認する。これは理事長ヒアリングとは別に、実務部門へのアプローチが要る。**

| 価値 | 内容 |
|---|---|

## 5-b. [追記 2026-09-11] メディカルツーリズムの再定義

町田の発言（→ 17 の3-7）**[U]**：

> メディカルツーリズムだって、ただ手術して、高度医療で手術して帰るだけじゃなくて、**そこで日本人とちょっと文化とか知見を学んで帰ったりしたら変わるのに。**
> 今のメディカルツーリズムは、本当に心が豊かにはなってないから。**医療・健康を金で買うってだけだから。**
> 健康を金で買うだけじゃなくて、**心も満たされて帰ってくれれば、日本に対してのリスペクトも増える。**

### 含意

| | 一般的なメディカルツーリズム | この場所が目指しうるもの |
|---|---|---|
| 目的 | 高度医療を受ける | 医療を受け、**そこで何かを持ち帰る** |
| 滞在 | 手術と回復。移動と入院 | 回復の時間を、島と人の中で過ごす |
| 価値 | 健康を金で買う | 健康と、**文化・知見・関係** |
| 結果 | 治って帰る | **日本に対するリスペクトが増える** |

**[H] これは「ホスピタリティを伴う医療滞在」という再定義である。**
そして、この再定義ができるのは **医療機関が主体だから**である。ホテル事業者には医療がなく、病院には滞在の設計がない。**徳洲会＋我々にしか作れない領域にあたる。**

### [V] 重要な確認事項

向田からの情報 **[U]**：

> 新しい病院の方で（メディカルツーリズムを）目指したいと、もともと言っていたが、**なかなかハードルがあるらしい。**

**そのハードルが何かを確認する。**（→ 16 のヒアリング項目D）
新病院側で成立しないものが、**旧病院側でなら成立する可能性がある**（滞在・回復・文化体験は、急性期病院では担えない）。
これは本構想にとって、重要な参入点になりうる。

**[!] ただし医療法・広告規制の壁は厳格である（→ 14 D-1・D-2）。**「治療」と「滞在」の線引きを、法務確認なしに設計しない。

## 6. やってはいけないこと

1. **健康効果を訴求しない。** 医療法・景品表示法の規制対象。宿泊施設が健康効能を謳うことは重大なリスク（→ 14）
2. **「長寿の島だから健康になる」と言わない。** 因果が示されていない
3. **島民を研究対象として扱わない。** 研究倫理以前に、地域との信頼を壊す。**島民は共同研究者である**という設計にする
4. **データを島の外へ持ち出すだけの構造にしない。** 島に還元されない研究は続かない
