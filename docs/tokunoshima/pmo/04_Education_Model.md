# 04 ｜ Education Model

**子ども〜社会人までの人材育成モデル。[H] 仮説。**

---

## 1. 中心にある考え方

> **医療を受ける機会が平等であるべきなら、
> 医療や生命の未来を志す機会も、できる限り平等であっていい。**

これは「生命だけは平等だ」の次世代への拡張である。

### 誤解を避けるための明記

**「誰でも医師になれる」という主張ではない。**
医学部入試、医学教育、国家試験を突破する必要は当然ある。

伝えたい思想は一つだけである。

> **人の可能性を、現在の成績、生まれ、国籍、親の職業、経済状況だけで決めない。**

---

## 2. 対象を限定しない

「勉強のできる優秀な医師志望者」に限定しない。以下も等しく対象とする。

- やんちゃな子／ガキ大将的なリーダーシップを持つ子
- 学校の成績だけでは評価されにくい子
- 元ヤン的なバックグラウンドを持つ若者
- 不登校経験者
- 障がいのある子
- 離島・地方の子
- 経済的に恵まれていない子
- 親が医療関係者ではない子
- 外国にルーツを持つ子
- 日本以外の国の子

### [F] この方針には、世界的な先行実証がある

**Barefoot College（インド・ティロニア）** は、非識字・半識字の農村女性を「太陽光エンジニア」として育成してきた。単身・中年・離婚・障がい・非識字といった、**最も機会から遠い women を優先的に選抜**する。色分け、手話、実地訓練など非文字的な教育手法を用いる。これまで96か国から1,700人超を訓練し、7万5,000戸以上を電化した。
（出典：Barefoot College International、インド新再生可能エネルギー省、Skoll財団）

> **学力で人を選ばない教育は、理想論ではない。すでに国際規模で成立している。**

---

## 3. 育てたい人材（「未来の医師」に限定しない）

**「生命の未来を良くする人」全般**を対象とする。

| 領域 | 職能 |
|---|---|
| 臨床 | 医師、看護師、医療従事者、救急、離島医療 |
| 研究 | 医学研究者、Longevity研究者、バイオ研究者、公衆衛生 |
| 技術 | 医療機器開発、Digital Health、AI Healthcare、遠隔医療 |
| 事業 | Healthcare Entrepreneur、社会起業家 |
| 予防・生活 | 予防医療、食・栄養・運動・睡眠の研究者 |
| 制度 | 医療政策、行政、国際保健 |
| 表現・環境 | デザイナー、建築家、アーティスト、環境の実践者 |

---

## 4. プログラム構成（[P] 提案）

### A. Children / Junior Program（小学生〜中学生）

| 要素 | 内容 |
|---|---|
| 医療 | 救急体験、身体の仕組み、いのちの授業 |
| 倫理 | 生命倫理の入口。「助けるとは何か」 |
| 自然 | 森・海・生物多様性のフィールド |
| 地域 | 島の高齢者との対話、島の仕事 |
| STEAM / Art | 手を動かす。作る |
| Problem Solving | 島の実課題に触れる |

**[P] 設計上の禁止事項：「病院版キッザニア」で終わらせない。**
職業体験の羅列にしない。**専門家と実際に話し、実際の課題に触れることが中心**であり、体験コンテンツは従属させる。

### B. Teen Challenge Program（中高生）

中心となる問い：

> **「生命だけは平等だ。では、あなたが変えたい"不平等"は何か？」**

- 期間：1〜2週間の滞在型
- 構成：世界・日本・徳之島の若者による混成チーム
- 流れ：課題発見 → フィールドワーク → 解決案 → プロトタイプ → 発表
- **島の子が必ず各チームに入る**（島の子が「教えられる側」に固定されない設計）

[F] 参考：**Island School（バハマ）** は高校生向け14週間セメスターで、学生が Cape Eleuthera Institute の研究者の実プロジェクトに参加する構造をとる。

### C. Medical Student / Young Professional Program

離島医療／地域医療／救急／公衆衛生／医療倫理／Planetary Health／国際医療。

[F] 徳洲会は全国に病院群を持ち、40施設に臨床試験センターを擁する。**研修・実習の受け皿としての基盤はすでにある。**
[V] 現在の医学生・研修医の徳之島受入実績は要確認（→ 07）。

### D. Healthcare Innovation Residency

研究者・スタートアップ・企業R&D・医療者が一定期間滞在し、研究・実証・プロトタイプ開発を行う。

[F] 参考：**Sheba Medical Center ARC（イスラエル）** は、病院内に startup が入り、医師・データに直接アクセスして院内で実証する仕組みを2019年から運用。年20〜30社、累計100社超。**このモデルは ARC Ottawa、Boston へ輸出されている**（出典：Sheba Medical Center、Jerusalem Post、Boston Globe）。
**→ 「病院グループが innovation hub を持ち、それを外部展開する」形は、実証済みである。**

### E. Longevity Program

食／運動／睡眠／社会的つながり／自然／海／予防医療／健康寿命を、徳之島という Living Lab で考える（→ 05）。

## 5. アクセス設計 ── 「生命だけは平等だ」をビジネスモデルに実装する

理念だけで終わらせない。経済的に恵まれないが志のある若者が来られる仕組みを設計する。

### 財源候補

Scholarship／企業スポンサー／徳洲会基金／寄付／ふるさと納税／財団助成／**一般宿泊収益からのクロスサブシディ**／卒業生寄付／海外財団／CSR・CSV／大学連携。

### [F] クロスサブシディの実証モデル

| 事例 | 仕組み | 実績 |
|---|---|---|
| **Aravind Eye Care（インド）** | 有料患者の収益で無料・低額患者を賄う。**全額支払う患者1人が3〜4人分を補助する構造** | 患者の約70%が無料または低額で治療を受ける（出典：McKinsey、NCBI、Business Model Toolbox） |
| **Fogo Island Inn / Shorefast（カナダ）** | **営業余剰の全額を地域に再投資**する社会的企業。宿・工房・水産業を運営 | 200名超を雇用。島の非政府GDPの20%超（出典：Shorefast、The Conversation） |
| **Sumba Foundation / NIHI Sumba（インドネシア）** | 財団資金の**80%超が宿泊客の寄付**。健康・水・教育に投下 | マラリア93%減、診療所5か所、延べ40万人超の治療、3万人に清潔な水（出典：Sumba Foundation、NIHI） |
| **Chumbe Island Coral Park（ザンザニア）** | エコロッジ収益で海洋保護区の運営と**無料の環境教育**を賄う | ザンジバルの生徒1万人超を無償で受け入れ（出典：CHICOP、Marine Conservation Institute） |
| **神山まるごと高専（徳島）** | 11社から**100億円規模の基金**を集め、運用益で学費を実質無償化 | 1学年40人・5年制・全寮制（出典：日本経済新聞、Business Insider Japan） |

> **[H] 「一般宿泊者が泊まることで、志のある若者が来られる」構造を、設計の中心に置く。**
> これは徳田虎雄の「差額ベッド代を取らない／入院保証金不要」の思想を、そのまま事業モデルに翻訳したものになる。

**[V] 検証事項：** クロスサブシディ比率、必要基金規模、税制（公益法人・寄付控除・ふるさと納税）、運営主体の法人形態。

## 6. アクセシビリティ ── 病院だからできる「誰でも」

既存資料 `../25_equal-access.md` の内容を本モデルに接続する。

病院は最初からストレッチャーが通る廊下、大型エレベーター、段差のない床、広いトイレ、手すりを持つ。**普通のホテルが後付けでは到達できない水準を、改修費ゼロで保有している。**

**設計原則：「バリアフリー対応の部屋」を作らない。全室がそうである状態を作る。**
分けた瞬間に「配慮」になる。分けないことが「平等」である。

**[V] 躯体・設備の残存状況、現行基準への適合、エレベーター更新の要否を確認する。**

## 7. 成果指標（KPI案）

宿泊者数だけで測らない。

| 区分 | 指標 |
|---|---|
| 規模 | 年間プログラム参加者数、うち島内・国内・海外の内訳 |
| 平等 | 奨学枠での参加者数と比率、参加者の世帯収入分布 |
| 継続 | Alumni 登録者数、再訪率、Alumni 間の協働件数 |
| 転換 | **「進路が変わった」と回答した参加者数**（追跡調査） |
| 長期 | 10年後の Alumni の職業分布、島出身者の医療職就業数と島内還流数 |
| 島 | 島内の子どもの参加率、島内雇用、島民の利用数 |

**[V] 追跡調査は設計時から組み込まないと、後から取れない。** 初年度から個人情報の取り扱いを含めて設計する。

---

## 8. 注意

1. **「島の子が教えられる側」に固定しない。** 混成チームでは島の子がフィールドの案内役＝教える側になる設計にする
2. **貧困や障がいを、物語の題材にしない**
3. **成果を出さない子を失敗としない。** 「進路が決まらなかった」ことは成果の否定ではない
4. 医学部進学実績を主要KPIにしない。**それを指標にした瞬間に、対象が優等生に戻る**
