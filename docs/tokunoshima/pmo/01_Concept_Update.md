本日の議論を統合したコンセプトメモ。**[H] 仮説であり、確定コンセプトではない。**

---

## 1. 何が変わったか

これまでの中心仮説は「旧病院という歴史的資産を活用した、徳之島ならではの Regenerative Destination Hotel」だった。**これは捨てない。**

しかし、上位に別の存在意義が見えてきた。

| | 旧 | 新 |
|---|---|---|
| 問い | 旧病院をどんなホテルにするか | **なぜ徳洲会は旧病院を残すのか** |
| レガシーの残し方 | 建物を残すことで思想を保存する | **思想を持った人間を生み出し続けることで保存する** |
| 成果指標 | 宿泊者数・ADR・稼働率 | それに加えて**「徳之島で人生の方向が変わった人」の数** |
| 施設の性格 | 目的地としてのホテル | **人が育ち、世界へ出ていく国際拠点。ホテルはその装置** |

> **[H] 旧病院は「徳田虎雄の思想を記念する施設」ではなく、
> 「徳田虎雄の思想を持った次世代を生み出し続ける場所」として再生する。**

---

## 2. この転換を支える三つの新事実

調査で確認された事実が、この仮説を後押ししている。

### [F] 旧病院は「徳洲会グループ初の離島病院」である

徳之島徳洲会病院は1986年10月、**徳洲会グループ初の離島病院**として開院した。2025年10月1日、約1.5km離れた高台に新築移転（199床→218床、12月までに237床）。移転理由は約40年経過による建物・設備の老朽化。
（出典：徳洲会グループ医師リクルートサイト、南海日日新聞、奄美新聞）

**含意：** この建物は「島の病院の一つ」ではない。**徳洲会が離島医療へ出ていった最初の一歩そのもの**である。「なぜ残すのか」の答えは、ここに直接ある。

### [F] 徳田虎雄顕彰記念館は、すでに存在する

新病院は「徳田虎雄顕彰記念館を間近に臨む高台」に立地している。
（出典：徳洲会グループ医師リクルートサイト）

**含意：** **記念館はもうある。だから旧病院が記念の役割を負う必要はない。** 「記念館にしない」は、思想的な選択であると同時に、機能的にも重複回避として正しい。旧病院に求められるのは、保存ではなく**生成**である。

### [F] 徳洲会は、すでに全国規模の臨床研究インフラを持っている

徳洲会グループは臨床試験部会を「司令塔」とし、**40施設で臨床試験センターが稼働**。医療情報データベース研究、各種倫理審査委員会（弁護士・臨床薬理学者・生物統計学者・生命倫理学者等）を擁する。
（出典：徳洲会 臨床試験部会、徳洲会グループ臨床研究サイト）

**含意：** Living Lab 構想は、ゼロからの研究機能立ち上げではない。**既存の全国ネットワークに「離島のフィールド」を一つ足す**という設計にできる。実現可能性が大きく変わる。

## 3. 更新後の構想

```
           旧徳之島徳洲会病院（1986-2025）
        徳洲会グループ初の離島病院／約40年
                      │
                      ▼
        ┌─────────────────────────────┐
        │   生命だけは平等だ を、        │
        │   病院の外で実装する          │
        └──────────────┬──────────────┘
                       │
     ┌─────────────────┼─────────────────┐
     ▼                 ▼                 ▼
  HOSPITALITY       EDUCATION         LIVING LAB
  泊まる・混ざる      育つ・出会う        調べる・試す
     │                 │                 │
     └─────────────────┼─────────────────┘
                       ▼
           徳之島から世界へ出ていく人
              Alumni Network
```

三つの機能は並列ではない。
**HOSPITALITY が収益と偶発的出会いを生み、EDUCATION と LIVING LAB がその出会いに意味を与える。**

## 4. Working Hypothesis（確定コピーにしない）

> 旧病院を残す目的は、徳田虎雄という人物を記念することだけではない。
>
> 「生命だけは平等だ」と信じ、常識にとらわれず、それを実現するために行動できる人間を、
> 徳之島から世界へ送り出し続ける。
>
> 医師を目指す子も、まだ将来が決まっていない子も、研究者も、起業家も、医療者も、
> 日本人も外国人もここに集う。
>
> 人の生命、地域の生命、自然の生命について学び、研究し、実験し、挑戦する。
>
> 旧徳之島徳洲会病院を、生命の未来をつくる人が集まり、育ち、世界へ出ていく国際的な拠点へ再生する。

## 4-b. [追記 2026-09-11] 方向性がさらに動いた

チーム内打合せ（→ 17）で、町田から次の発言があった。**[U]**

> ラグジュアリーホテルを作るわけじゃないでしょう。
> ある種、**キッザニアの医療版だけみたいになっちゃってもいいぐらい**で、
> もうちょっと多分、**日本で医師を育てる、育成しないとダメだと思う。**

### 変化の内容

| | 従来 | 今回 |
|---|---|---|
| 宿泊の位置づけ | 収益の主体。高価格帯 | **収益基盤ではあるが、中心ではない** |
| 中心 | ブランドとしてのホテル | **教育** |
| 振れ幅 | 慎重に統合 | **「キッザニア医療版でもいい」＝振り切ってよい** |

### 同時に出た、教育の中身についての指示

- **「東京のお医者の息子が来てもらっても困る」「医療に関わる人を平等にしたい」**
- 美容医療偏重への問題意識。**「医療はホスピタリティがあって、人間としてのプライドがある仕事だ」と教えるカリキュラムが足りない**
- 医師会と**正面からではなく「手前（教育段階）」で戦う**
- キューバ（ELAM）モデル。**離島から育った医師が世界へ**（→ 08 A-15）

### [!] ただし、事業性と衝突する

教育中心の価格帯（ADR 15,000〜22,000円）では、30億円の単純回収は**16〜24年**になる。
**回収を求めるなら成立しない。**（試算は → 17 の4節）

したがって選択肢は三つ。**1 は徳洲会に確認するしかなく、2＋3 が我々の設計領域である。**

1. 30億円を「回収を求めない投資」と位置づける
2. **クロスサブシディ**（一般宿泊・企業研修の収益が教育を支える。Aravind型 → 08 A-5）
3. **教育そのものを収益事業にする**（企業研修・医学生研修・海外プログラム）

> **[P] 2＋3 を推奨する。**
> **一般の宿泊者が泊まることで、志のある子どもがここに来られる。**
> これなら、ラグジュアリーであることと教育であることが、矛盾ではなく**因果**になる。

### [!] アクセス経路も変わった

**最初の面談相手は理事長ではなく、現・事務局長＝次期ホテル総支配人（見込み）である。**
専用ガイドを 16 に作成した。**11（理事長ヒアリング）は第二段階へ後ろ倒しする。**
