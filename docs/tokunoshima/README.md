## 進め方の原則

1. 最初から「Regenerative Hotel」を答えとしない。アート・リジェネラティブ・ウェルネスは手段であって目的ではない。
2. 初回面談は **提案3：ヒアリング7**。
3. WHY / BUSINESS / PLACE / AMBITION を確認する前に、ブランドコンセプトを決定しない。
4. ENOWAを徳之島にコピーしない。ENOWAを生み出したブランド開発思想を適用する。

詳細は [`00_project-premise.md`](00_project-premise.md) を参照。

## 未確定事項（初回面談で確認）

- 投資額（約30億円）／客室数／カテゴリー／ターゲット／オペレーター／開業時期／設計進捗
- 旧病院の稼働年数・開設年・躯体状態・残したい範囲
- 目指す高さ（島／奄美／日本／世界）
- 徳田虎雄氏のレガシーとの関係についての理事長のお考え
